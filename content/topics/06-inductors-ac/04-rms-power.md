## Как это устроено

RMS выбирает такое эквивалентное постоянное значение по средней мощности. Для синусоиды Urms=Uпик/√2, но для других форм нужна их собственная формула или True RMS-прибор с подходящей полосой.

## Модель и единицы

Uпик = √2·Urms только для синусоиды; размах равен 2Uпик.

Сравни тип прибора и форму сигнала. Для прямоугольных импульсов не дели пик на √2 автоматически.
