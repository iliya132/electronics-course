Серво и моторы — первые «мощные» нагрузки в проектах на Arduino. Именно здесь начинающие впервые сталкиваются с просадками питания, перезагрузками и перегревом. Правила простые, но их нужно соблюдать.

## Servo.h

Серво — это мотор с редуктором, датчиком положения и управляющей электроникой. Три провода: питание (красный), земля (коричневый/чёрный), сигнал (жёлтый/оранжевый). Угол задаёт импульс 1–2 мс каждые 20 мс. Библиотека `Servo.h` скрывает детали.

```cpp
#include <Servo.h>

Servo s;

void setup() {
  s.attach(9);          // сигнал серво на D9
}

void loop() {
  s.write(0);   delay(1000);   // 0°
  s.write(90);  delay(1000);   // 90°
  s.write(180); delay(1000);   // 180°
}
```

## Питание и общая земля

Серво и моторы питают от **отдельного источника** 5–6 В (2 А и более). Земля внешнего источника соединяется с GND Arduino — иначе сигнал не имеет опоры. Параллельно питанию серво ставят электролитический конденсатор 470–1000 мкФ: он гасит просадки при пуске. Не питайте серво от вывода 5V платы при токах свыше 200 мА.

## Моторы через MOSFET

Для щёточного мотора ставят N-MOSFET (IRLZ44N): сигнал ШИМ с вывода Arduino подаётся на затвор через резистор 100 Ом, затвор подтянут к земле резистором 10 кОм, **диод параллельно мотору** (катодом к плюсу) защищает ключ от выброса. Питание мотора отдельное, земля общая. Скорость регулируется `analogWrite()`.

```cpp
const int MOTOR = 5;     // ШИМ на затвор MOSFET

void setup() {
  pinMode(MOTOR, OUTPUT);
}

void loop() {
  for (int v = 0; v <= 255; v += 5) { analogWrite(MOTOR, v); delay(40); }   // разгон
  delay(1000);
  for (int v = 255; v >= 0; v -= 5) { analogWrite(MOTOR, v); delay(40); }   // торможение
}
```

```callout
kind: safety
text: "Не подключай мотор или серво к выводу Arduino напрямую и не питай их от 5V платы при больших токах. Мощные моторы разгоняй плавно, не держи их в стопоре: обмотки и ключ перегреваются. Работай с низковольтными источниками (до 12 В) и заводскими блоками питания; пальцы держи вдали от вращающихся частей."
```

```callout
kind: mistake
text: "Питают серво от 5V платы и не соединяют земли внешнего питания и Arduino. Серво дёргается или не слушается: у сигнала нет общего опорного уровня. Земли внешнего источника и Arduino обязательно соединяют."
```
