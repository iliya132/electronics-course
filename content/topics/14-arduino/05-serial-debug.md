Отладка на МК — это не «поставить точку останова», а «распечатать значение». Serial — канал связи платы с компьютером через USB. Через него можно вывести всё, что нужно понять о работе программы.

```predict

options:
  - Правильный текст
  - Набор непонятных символов
  - Ничего, ошибка загрузки
answer: 1
reveal: Приёмник считывает биты в другом темпе и получает мусор. Скорость в программе и в мониторе обязана совпадать.
```

## Вывод в монитор порта

```cpp
void setup() {
  Serial.begin(9600);          // скорость 9600 бод
}

void loop() {
  int raw = analogRead(A0);
  float volts = raw * 5.0 / 1024;
  Serial.print("A0 = ");       // без перевода строки
  Serial.print(raw);
  Serial.print(" (");
  Serial.print(volts, 2);      // 2 знака после запятой
  Serial.println(" В)");       // с переводом строки
  delay(500);
}
```

`Serial.print` выводит значение, `Serial.println` добавляет перевод строки. Для дробных чисел второй аргумент — число знаков после запятой. Откройте монитор: Tools → Serial Monitor (Ctrl+Shift+M), выберите ту же скорость.

## Кадр UART и скорость

Каждый байт передаётся кадром: **старт-бит** (0), 8 бит данных (младший первым) и **стоп-бит** (1). Всего 10 бит на байт. При скорости 9600 бод (бит/с) передаётся 960 байт/с, значит один байт занимает 1,04 мс.

```example

steps:

  - "Если программа выводит строку каждые 10 мс, вывод не успевает: буфер переполняется и программа замедляется."

```

## Плоттер и отладка

Serial Plotter (Tools → Serial Plotter) строит график чисел, выводимых по одному в строке (`Serial.println(value)`); несколько значений разделяют пробелом или запятой. Это удобный способ увидеть шум потенциометра или реакцию датчика. Типичные ошибки: несовпадение скорости, лишний вывод в быстром цикле, использование Serial при выводах D0 и D1 (они заняты UART).

```callout
kind: mistake
text: "Выводят отладочные сообщения в каждом проходе быстрого цикла: Serial.println на 9600 бод занимает десятки миллисекунд, и программа начинает пропускать события. Выводи редко (раз в 100–500 мс по millis()) или повышай скорость до 115200."
```

```callout
kind: board
text: "Светодиоды TX и RX на плате Arduino мигают при обмене по Serial: по ним видно, идёт ли связь. Выводы D0 (RX) и D1 (TX) нельзя использовать, пока работает Serial."
```
