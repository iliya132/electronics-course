## Неблокирующая задержка

Функция `millis()` возвращает время в миллисекундах с запуска МК. Мигалка без delay(): запоминаем момент последнего переключения и переключаем снова, когда пройдёт интервал.

```cpp
const int LED = 13;
const unsigned long INTERVAL = 500;   // мс
unsigned long prev = 0;
bool state = false;

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  unsigned long now = millis();
  if (now - prev >= INTERVAL) {       // пора переключать?
    prev = now;
    state = !state;
    digitalWrite(LED, state);
  }
  // здесь можно делать другие дела: читать кнопки, датчики…
}
```

`millis()` — число типа `unsigned long` (32 бита): переполняется через 2³² мс ≈ **49,7 суток**. Выражение `now - prev` работает правильно и после переполнения, поскольку беззнаковая арифметика «заворачивается».

## Конечный автомат

Когда программа ведёт себя по-разному в разных ситуациях, её описывают как **конечный автомат**: набор состояний и правил перехода. Светофор — классический пример: красный → зелёный → жёлтый → красный. В каждом состоянии программа запоминает момент входа и сравнивает `millis()` с длительностью состояния.

```figure
file: millis-fsm/states.svg
alt: "Диаграмма состояний светофора: красный 5 с, зелёный 4 с, жёлтый 1,5 с. Стрелки по кругу красный → зелёный → жёлтый → красный, на каждой подпись: время вышло. Пояснение: в каждом состоянии запоминают момент входа и сравнивают millis с длительностью."
caption: "Конечный автомат светофора: три состояния и переходы по времени."
```

```cpp
// Светофор: красный 5 с → зелёный 4 с → жёлтый 1,5 с
enum State { RED, GREEN, YELLOW };
State state = RED;
unsigned long entered = 0;                  // момент входа в состояние

const int R = 10, Y = 9, G = 8;

void setLights(bool r, bool y, bool g) {
  digitalWrite(R, r); digitalWrite(Y, y); digitalWrite(G, g);
}

void setup() {
  pinMode(R, OUTPUT); pinMode(Y, OUTPUT); pinMode(G, OUTPUT);
  setLights(true, false, false);
}

void loop() {
  unsigned long dur = (state == RED) ? 5000 : (state == GREEN ? 4000 : 1500);
  if (millis() - entered >= dur) {
    entered = millis();
    if (state == RED)        { state = GREEN;  setLights(false, false, true); }
    else if (state == GREEN) { state = YELLOW; setLights(false, true, false); }
    else                     { state = RED;    setLights(true, false, false); }
  }
}
```

## Правила и ошибки

Автомат хранит состояние в одной переменной; действия при переходе выполняются один раз при входе в состояние. `millis()` сравнивают разностью `now - prev >= интервал`, а не `now >= prev + интервал`, иначе после переполнения программа зависнет. Для нескольких задач заводят свою переменную времени на каждую.

```callout
kind: mistake
text: "Пишут if (millis() >= prev + INTERVAL): после переполнения millis() (через 49,7 суток) условие становится ложным надолго, и задача «замирает». Правильно: if (millis() - prev >= INTERVAL) — беззнаковое вычитание корректно переживает переполнение."
```

```callout
kind: board
text: "Светофоры, стиральные машины, лифты и кофеварки работают как конечные автоматы: в каждый момент устройство находится в понятном состоянии (наполнение, нагрев, слив), а переходы определяют время и датчики."
```
