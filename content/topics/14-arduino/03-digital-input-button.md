## Как это устроено

## Проверяем на практике

Не оставляй вход плавающим. Измеряй время устойчивости через millis и проверяй переход состояния, если нужно одно событие на нажатие.

До подключения найди общий провод и проверь режим прибора. Изменяй один параметр за раз, записывай расчёт и измерение. Несовпадение сначала проверь по единицам и условиям модели.

```cpp
const byte buttonPin=2;
bool rawOld=HIGH, stable=HIGH;
unsigned long changed=0;
void setup(){ pinMode(buttonPin,INPUT_PULLUP); pinMode(13,OUTPUT); }
void loop(){
 bool raw=digitalRead(buttonPin);
 if(raw!=rawOld){ changed=millis(); rawOld=raw; }
 if((unsigned long)(millis()-changed)>=30) stable=raw;
 digitalWrite(13,stable==LOW);
}
```
