## INPUT_PULLUP

Режим `pinMode(2, INPUT_PULLUP)` включает внутреннюю подтяжку 20–50 кОм: внешний резистор не нужен. Кнопку подключают между выводом и GND. Логика получается **инвертированной**: отпущена — HIGH, нажата — LOW. Ток через подтяжку при нажатии 5 В / 30 кОм ≈ 0,17 мА.

```cpp
const int BUTTON = 2;
const int LED = 13;

void setup() {
  pinMode(BUTTON, INPUT_PULLUP);   // кнопка между D2 и GND
  pinMode(LED, OUTPUT);
}

void loop() {
  // LOW — кнопка нажата
  digitalWrite(LED, digitalRead(BUTTON) == LOW ? HIGH : LOW);
}
```

## Дребезг

В момент нажатия контакты упруго отскакивают и замыкаются несколько раз в течение 1–20 мс. Быстрый МК читает их как несколько нажатий. Если считать нажатия и каждое переключать светодиод, результат будет случайным.

## Программное подавление

Идея: принимать новое состояние кнопки, только если оно держится дольше 30 мс. Для этого запоминают время последнего изменения по `millis()`.

```figure
file: digital-input-button/debounce-flow.svg
alt: "Алгоритм подавления дребезга: читаем кнопку, проверяем, изменилось ли значение; если да — запоминаем время millis; если прошло не менее 30 мс с последнего изменения — принимаем состояние. Подпись: если значение не менялось дольше 30 мс, это устойчивое состояние."
caption: "Подавление дребезга без delay(): состояние принимают после 30 мс стабильности."
```

```cpp
const int BUTTON = 2, LED = 13;
const unsigned long DEBOUNCE_MS = 30;

bool lastRaw = HIGH;          // последнее «сырое» значение
bool stable = HIGH;           // принятое устойчивое значение
unsigned long lastChange = 0;
bool ledOn = false;

void setup() {
  pinMode(BUTTON, INPUT_PULLUP);
  pinMode(LED, OUTPUT);
}

void loop() {
  bool raw = digitalRead(BUTTON);
  if (raw != lastRaw) {           // значение изменилось — сбросить таймер
    lastChange = millis();
    lastRaw = raw;
  }
  if (millis() - lastChange > DEBOUNCE_MS && raw != stable) {
    stable = raw;                 // новое устойчивое состояние
    if (stable == LOW) {          // фронт нажатия
      ledOn = !ledOn;             // переключить светодиод
      digitalWrite(LED, ledOn);
    }
  }
}
```
