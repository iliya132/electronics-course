## Цель

Соберём измеритель «мощности»: INA219 стоит в разрыве питания нагрузки и по I²C сообщает Arduino напряжение, ток и мощность; Arduino считает накопленную энергию. Проект закрепляет шунты, I²C и работу с библиотекой, а результат пригодится для оценки времени работы батарейных устройств.

## Что понадобится

- Arduino Uno или Nano.
- Модуль INA219 (шунт 0,1 Ом на плате, адрес 0x40), библиотека **Adafruit_INA219**.
- Нагрузка: светодиодная лента или резистор 10 Ом 5 Вт, лабораторный блок питания WANPTEK TPS3010 (5,00 В, предел тока 1 А) как источник.
- Мультиметр Rigol DM858E для проверки и осциллограф Rigol DHO804 для просмотра броска тока.

## Расчёт

- **Мощность:** P = U·I. Для 5 В и 0,2 А: **1 Вт**.
- **Энергия за 1 час:** 1 Вт · 1 ч = **1 Вт·ч**.
- **Время работы батареи:** Li-ion 2000 мА·ч × 3,7 В = 7,4 Вт·ч; при нагрузке 1 Вт — 7,4 ч (полезная энергия ~ 80 % → 6 ч).
- **Диапазон INA219:** шунт 0,1 Ом, PGA ±320 мВ → до 3,2 А; шаг по току 0,1 мА (калибровка 32 В, 2 А).
- **Падение на шунте:** 0,2 А · 0,1 Ом = 20 мВ — на нагрузке 4,98 В.
- **Ошибка шунта 1 %:** при 0,2 А ±2 мА.

## Сборка по шагам

1. Отключи питание. Модуль INA219: VCC → 5V, GND → GND, SDA → A4, SCL → A5.
2. Силовая цепь: «+» источника → VIN+ INA219; VIN− → «+» нагрузки; «−» нагрузки и «−» источника → общая земля с Arduino.
3. Установи библиотеку Adafruit_INA219.
4. Загрузи скетч:

```cpp
#include <Wire.h>
#include <Adafruit_INA219.h>

Adafruit_INA219 ina;
unsigned long last = 0;
float energy_mWh = 0;

void setup() {
  Serial.begin(115200);
  if (!ina.begin()) {                  // по умолчанию калибровка 32 В, 2 А
    Serial.println("INA219 не найден");
    while (true) {}
  }
}

void loop() {
  unsigned long now = millis();
  if (now - last >= 1000) {
    float dt_h = (now - last) / 3600000.0;     // интервал в часах
    last = now;
    float busV = ina.getBusVoltage_V();        // напряжение шины, В
    float mA = ina.getCurrent_mA();            // ток, мА
    float mW = ina.getPower_mW();              // мощность, мВт
    energy_mWh += mW * dt_h;                   // накопленная энергия, мВт·ч
    Serial.print(busV, 2);  Serial.print(" В, ");
    Serial.print(mA, 1);    Serial.print(" мА, ");
    Serial.print(mW, 0);    Serial.print(" мВт, ");
    Serial.print(energy_mWh, 2); Serial.println(" мВт·ч");
  }
}
```

## Проверка

Ожидай: для резистора 10 Ом при 5 В ток около 480 мА (с учётом шунта), мощность 2,4 Вт; расхождение с мультиметром не более 2–3 %. Накопленная энергия за 10 минут ≈ 0,4 Вт·ч = 400 мВт·ч.

## Если не работает

- **Ток равен нулю.** Нагрузка не включена через VIN+/VIN−: ток должен идти через шунт.
- **Ток отрицательный.** Перепутаны VIN+ и VIN− (направление).
- **Напряжение шины некорректно.** Земля источника не соединена с GND модуля.
- **Показания отличаются от мультиметра больше 5 %.** Проверь шунт и калибровку (setCalibration_16V_400mA для малых токов).
- **I²C «висит».** Подтяжки, длинные провода или два модуля с одним адресом.


## Идеи развития

- Выведи значения на LCD или OLED и построй график мощности в Serial Plotter.
- Сохраняй накопленную энергию в EEPROM раз в несколько минут (не чаще!).
- Добавь отсечку нагрузки по превышению тока через реле.
- Сравни два зарядных кабеля по падению напряжения под нагрузкой.

```checkpoint

  - Включай INA219 в плюсовой провод (VIN+ → VIN−), общая земля; сравнивай показания с мультиметром.
```
