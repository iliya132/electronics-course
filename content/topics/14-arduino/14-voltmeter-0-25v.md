## Цель

Соберём низковольтный вольтметр с запасом входного диапазона. Делитель уменьшает измеряемое напряжение, затем код АЦП пересчитывается обратно. Исходные 30 кОм/7,5 кОм дают ровно 5 В при 25 В без запаса; выберем 33 кОм/6,8 кОм.

## Что понадобится

- Arduino Uno R3, USB-кабель данных
- Макетная плата и перемычки
- R1=33 кОм, R2=6,8 кОм с малым допуском
- Входная защита по спецификации ATmega328P
- Мультиметр и ограниченный DC-источник

Бюджет: сначала используй детали своего набора. Для планирования можно заложить 1500–5000 ₽ без измерительных приборов; это условный резерв, актуальные цены проверяй перед покупкой.

## Расчёт

Uвых = Uвх·R2/(R1+R2); одинаковые приставки сопротивлений сокращаются. 1 кОм = 1000 Ом.

## Сборка по шагам

1. С отключённым A0 собери вход → 33 кОм → выход → 6,8 кОм → GND.
2. Проверь выход при нескольких напряжениях до 25 В.
3. Проверь защиту и режим без питания Uno; затем подключи A0 и общий GND.
4. Измерь реальную опору 5 В, внеси measuredReference, откалибруй по мультиметру.

[Скачать скетч .ino](/examples/voltmeter-0-25v/voltmeter-0-25v.ino)

```cpp
const float measuredReference=5.00f;
const float ratio=(33000.0f+6800.0f)/6800.0f;
void setup(){Serial.begin(9600);}
void loop(){
 long sum=0;for(byte i=0;i<16;i++)sum+=analogRead(A0);
 float code=sum/16.0f;
 float voltage=code*measuredReference/1024.0f*ratio;
 Serial.println(voltage,3);delay(250);
}
```

## Проверка

При 25 В выход ≈4,271 В, коэффициент деления 39,8/6,8≈5,853. Сопротивление источника для АЦП около 5,638 кОм. Учебная цель ±2 % после калибровки; это не сертифицированный измеритель.

## Если не работает

- Неправильно подключены выводы или общий GND.
- Не совпадает адрес, тип модуля или библиотека.
- Источник проседает под нагрузкой.
```callout
kind: mistake
text: >-
  Ровно 5 В при предельном входе гарантирует безопасность с любыми допусками. При проектировании
  диапазона оставляют запас до предела АЦП.
```

## Безопасность

```callout
kind: safety
text: >-
  Только изолированные DC-цепи до 25 В. Сеть запрещена. Не подавай вход при обесточенном Uno без
  рассчитанной защиты от обратного питания.
```
