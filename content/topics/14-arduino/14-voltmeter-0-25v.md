## Цель

Соберём вольтметр постоянного тока на диапазон 0–25 В: делитель уменьшает напряжение до 0–5 В, а Arduino измеряет и выводит значение в Serial. Проект закрепляет делитель, защиту входа и калибровку.

## Что понадобится

- Arduino Uno или Nano.
- Резисторы 30 кОм и 7,5 кОм (допуск 1 %), резистор 1 кОм, стабилитрон 5,1 В, конденсатор 100 нФ.
- Лабораторный блок питания WANPTEK TPS3010: 0–24 В, предел тока 20 мА — **только низковольтный**. Он служит образцовым источником.
- Мультиметр Rigol DM858E как эталон.

## Расчёт

- **Коэффициент деления:** k = R2/(R1 + R2) = 7,5/37,5 = **0,2**.
- **Шаг:** при Uref = 5 В LSB АЦП = 4,88 мВ; на входе вольтметра 4,88/0,2 = **24,4 мВ**.
- **Диапазон:** 25 В → 5,0 В на A0.
- **Входное сопротивление:** 37,5 кОм; ток при 25 В: 25/37,5 кОм = **0,67 мА**.
- **Мощности:** на R1 (25 − 5)²/30 кОм = 13 мВт — подойдёт резистор 0,25 Вт.
- **Погрешность:** резисторы 1 % → до ±1,4 % по коэффициенту, плюс опорное напряжение (USB 5 В ±5 %). Без калибровки возможна ошибка 3–5 %.
- **Защита:** стабилитрон 5,1 В параллельно R2 и резистор 1 кОм перед A0: при перегрузке выше 25 В напряжение на A0 остаётся около 5,1 В.

## Сборка по шагам

1. Отключи питание. Собери делитель: вход «+» → R1 30 кОм → узел → R2 7,5 кОм → GND; «−» входа соедини с GND Arduino.
2. Стабилитрон 5,1 В поставь параллельно R2 (катод к узлу).
3. От узла через резистор 1 кОм подключи вход A0; параллельно A0–GND — конденсатор 100 нФ.
4. Загрузи скетч:

```cpp
const int PIN = A0;
const float K_DIV = 0.2;        // коэффициент делителя
const float VREF = 5.0;         // опорное напряжение (проверь мультиметром на 5V)
float calib = 1.0;              // поправка из калибровки

void setup() { Serial.begin(9600); }

void loop() {
  long sum = 0;
  for (int i = 0; i < 32; i++) sum += analogRead(PIN);   // усреднение
  float raw = sum / 32.0;
  float vPin = raw * VREF / 1024.0;
  float vIn = vPin / K_DIV * calib;
  Serial.print(vIn, 2);
  Serial.println(" В");
  delay(300);
}
```

5. Подавай 3, 6, 9, 12 В, сравнивай с мультиметром. Запиши.
6. Вычисли поправку calib = эталон / показание на 12 В и подставь в скетч.

## Проверка

Ожидай: до калибровки ошибка 1–4 %, после — не более 0,5 %; показания не «прыгают» (усреднение 32); при напряжении выше 25 В показание упирается около 25,5 В (стабилитрон). Резисторы не нагреваются.

## Если не работает

- **Показание равно 0.** Нет соединения «−» с GND Arduino или обрыв.
- **Показание в 5 раз больше.** Не подключён R2 или не учтён k = 0,2.
- **Показания «прыгают».** Нет конденсатора 100 нФ или слабое усреднение.
- **Показание упирается около 5 В.** Стабилитрон ограничил: сигнал выше диапазона.
- **При измерении мигают светодиоды Arduino или перезагружается МК.** Земли источника и Arduino не общие, либо превышено напряжение.

## Идеи развития

- Добавь второй канал (A1) для измерения тока по шунту.
- Выведи значение на LCD с точностью 0,1 В.
- Используй внутреннее опорное 1,1 В и делитель 22:1 для лучшей точности.
- Построй график напряжения в Serial Plotter.
