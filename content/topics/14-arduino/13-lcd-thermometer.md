## Цель

Соберём настоящий цифровой термометр: датчик NTC в делителе, Arduino считает температуру по формуле, LCD1602 показывает текущую и минимальную/максимальную температуры. Это объединяет аналоговый вход, формулы датчика, I²C-дисплей и работу с Serial.

## Что понадобится

- Arduino Uno или Nano.
- NTC 10 кОм (B = 3950), резистор 10 кОм 1 %.
- LCD1602 с I²C-модулем (PCF8574), кнопка, провода и макетная плата.
- Библиотека LiquidCrystal_I2C (Менеджер библиотек).
- Мультиметр Rigol DM858E, тестер LCR-P1 и резисторы 4,7; 6,8; 10 и 15 кОм для проверки без нагрева.

## Расчёт

- Делитель: 5 В → 10 кОм → узел A0 → NTC → GND. Код = 1024·Rn/(Rn + 10 кОм).
- **Rn = 10 кОм · код / (1024 − код)**; температура: 1/T = 1/298,15 + ln(Rn/10 кОм)/3950.
- **Разрешение:** чувствительность 37 мВ/°C ÷ 4,88 мВ ≈ 7,6 отсчёта на градус, то есть **0,13 °C/отсчёт**.
- Усреднение 16 отсчётов: шум в 4 раза меньше.
- Самонагрев NTC: ток 5 В / 20 кОм = 0,25 мА, мощность в NTC 0,6 мВт — незначителен.
- Погрешность: NTC 1 % даёт ±0,25 °C около 25 °C; резисторы 1 % — ещё ±0,3 °C.

## Сборка по шагам

1. Отключи питание. Собери делитель: 5 В → 10 кОм → A0 → NTC → GND.
2. Подключи LCD: VCC → 5V, GND → GND, SDA → A4, SCL → A5. Кнопка — между D2 и GND.
3. Установи библиотеку LiquidCrystal_I2C; при необходимости найди адрес I²C-сканером.
4. Загрузи скетч:

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);
const int NTC = A0, BTN = 2;
const float R_FIX = 10000.0, B = 3950.0, T0 = 298.15, R0 = 10000.0;

float tMin = 100, tMax = -100;

float readTemperature() {
  long sum = 0;
  for (int i = 0; i < 16; i++) sum += analogRead(NTC);   // усреднение 16 отсчётов
  float raw = sum / 16.0;
  float rn = R_FIX * raw / (1024.0 - raw);
  float k = 1.0 / (1.0 / T0 + log(rn / R0) / B);
  return k - 273.15;
}

void setup() {
  pinMode(BTN, INPUT_PULLUP);
  lcd.init(); lcd.backlight();
}

void loop() {
  float t = readTemperature();
  if (t < tMin) tMin = t;
  if (t > tMax) tMax = t;
  if (digitalRead(BTN) == LOW) { tMin = t; tMax = t; }   // сброс мин/макс

  lcd.setCursor(0, 0);
  lcd.print("T = "); lcd.print(t, 1); lcd.print(" C   ");
  lcd.setCursor(0, 1);
  lcd.print("min "); lcd.print(tMin, 1);
  lcd.print(" max "); lcd.print(tMax, 1);
  delay(500);
}
```

5. Сравни показания с бытовым термометром при комнатной температуре; обхвати NTC пальцами и посмотри, как растёт температура.
6. Запиши мин и макс, нажми кнопку и убедись, что значения сбросились.

## Проверка

Ожидай: ошибка не более ±1 °C в диапазоне 15–40 °C; показания спокойные (шум ±0,1 °C); температура растёт за 10–20 секунд после касания пальцем. Мин и макс обновляются, кнопка сбрасывает их.

## Если не работает

- **Дисплей пуст.** Проверь адрес (0x27 или 0x3F), подсветку и контраст подстроечником.
- **Температура −273 или NaN.** Код 0 или 1024: обрыв NTC или делителя; проверь соединения.
- **Показания сильно отличаются от эталона.** Проверь B-параметр (3950 или 3435) и сопротивление при 25 °C.
- **Значения «хвосты» на экране.** Дописывай пробелы после чисел.
- **Кнопка не сбрасывает.** Проверь подключение D2–GND и INPUT_PULLUP.

- Замени NTC на цифровой DS18B20 и сравни точность.
- Сохраняй мин и макс в EEPROM при изменении.
- Добавь вывод в Serial Plotter и график за сутки.
- Подключи зуммер: сигнал при температуре выше уставки.
