«Аналоговые» функции Arduino — это мост между числами и напряжениями. Мы читаем напряжение с потенциометра или датчика и выводим «аналоговый» сигнал через ШИМ. Разберёмся, что за этим стоит и как не запутаться в диапазонах.

```predict
  - Около 2,5 В
```

## analogRead

`analogRead(A0)` измеряет напряжение на входе A0 относительно опорного (по умолчанию 5 В) и возвращает число 0…1023. Шаг 5 В / 1024 = 4,88 мВ. Преобразование обратно: `U = raw * 5.0 / 1024`. Потенциометр 10 кОм между 5 В и GND с движком на A0 даёт напряжение от 0 до 5 В.

## map() и analogWrite

`map(x, 0, 1023, 0, 255)` переводит диапазон АЦП 0…1023 в диапазон ШИМ 0…255. Деление целочисленное, поэтому результат получается ступенчатым (и дробная часть отбрасывается). `analogWrite(pin, v)` задаёт ШИМ со скважностью v/255 на выводах 3, 5, 6, 9, 10, 11.

```figure
file: analog-pwm/map.svg
alt: "График функции map от 0 до 1023 в диапазон 0–255: почти прямая линия со ступенями; в точке 512 результат 127. Подпись: целочисленное деление, результат ступенчатый."
caption: "map(x, 0, 1023, 0, 255): линейное преобразование с отбрасыванием дробной части."
```

```cpp
// Яркость светодиода регулируем потенциометром
const int POT = A0;     // движок потенциометра
const int LED = 9;      // вывод с ШИМ

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  int raw = analogRead(POT);              // 0…1023
  int pwm = map(raw, 0, 1023, 0, 255);    // 0…255
  analogWrite(LED, pwm);                  // скважность pwm/255
}
```

```example
title: Яркость при положении потенциометра
steps:
  - "Движок на 30 % хода: напряжение 1,5 В, код 307 (1,5 · 1024/5)."
  - "map(307, 0, 1023, 0, 255) = 307·255/1023 = 76,5 → 76."
  - "Скважность 76/255 = 29,8 %; среднее напряжение 5 · 0,298 = 1,49 В."
  - "Яркость светодиода растёт почти линейно, хотя глаз воспринимает яркость нелинейно."
result: код 307, ШИМ 76, скважность 29,8 %
```

## ШИМ как «аналоговый» выход

`analogWrite(pin, 128)` даёт на выводе прямоугольник со скважностью 50 %. Вольтметр постоянного тока покажет около 2,5 В, но осциллограф — быстрые импульсы 0 и 5 В с частотой 490 или 980 Гц. Для светодиодов и моторов этого достаточно (они усредняют), а для питания чувствительной электроники нужен RC-фильтр.


```callout
kind: mistake
text: "Подают analogRead (0…1023) прямо в analogWrite (0…255). Значения выше 255 «заворачиваются» (analogWrite берёт младший байт), и яркость скачет. Диапазоны нужно приводить через map() или делить на 4."
```

```callout
kind: board
text: "Потенциометр на плате — небольшой синий корпус с винтом (подстроечный) или ручка; его выход идёт на аналоговый вход МК. Выводы с ШИМ на Arduino помечены «~». Яркость светодиодов в проектах почти всегда регулируется analogWrite."
```
