## Цель

Соберём светодиодный светодиод с логикой реального перекрёстка: красный → зелёный → жёлтый → красный, а нажатие кнопки пешехода во время зелёного сокращает его. Проект закрепляет конечный автомат, millis() и подавление дребезга.

## Что понадобится

- Arduino Uno или Nano, макетная плата, провода.
- Три светодиода (красный, жёлтый, зелёный) и три резистора 330 Ом.
- Тактовая кнопка.
- Если есть — зуммер для сигнала пешехода (по желанию).

Цены условные, проверяй актуальные.

## Расчёт

- **Ток светодиода:** (5 − 2) / 330 ≈ **9 мА** при одновременном свечении одного светодиода — в пределах 20 мА на вывод.
- **Длительности:** красный 5 с, зелёный 4 с, жёлтый 1,5 с; цикл **10,5 с**.
- **При запросе пешехода:** зелёный сокращается до 2 с (если прошло меньше 2 с — дожидаемся 2 с), поэтому цикл становится 8,5 с.
- **Дребезг:** порог 30 мс; кнопка INPUT_PULLUP, ток через подтяжку около 0,17 мА.

## Сборка по шагам

1. Отключи питание. Подключи светодиоды: анод через 330 Ом к D10 (красный), D9 (жёлтый), D8 (зелёный); катоды на GND.
2. Кнопку включи между D2 и GND.
3. Загрузи скетч:

```cpp
// Светофор с кнопкой пешехода
enum State { RED, GREEN, YELLOW };
State state = RED;
unsigned long entered = 0;                    // момент входа в состояние

const int R = 10, Y = 9, G = 8, BTN = 2;
const unsigned long RED_MS = 5000, GREEN_MS = 4000, YELLOW_MS = 1500, GREEN_MIN = 2000;

bool request = false;                         // запрос пешехода
bool stableBtn = HIGH, lastRaw = HIGH;
unsigned long lastChange = 0;

void setLights(bool r, bool y, bool g) {
  digitalWrite(R, r); digitalWrite(Y, y); digitalWrite(G, g);
}

void readButton() {                           // подавление дребезга 30 мс
  bool raw = digitalRead(BTN);
  if (raw != lastRaw) { lastChange = millis(); lastRaw = raw; }
  if (millis() - lastChange > 30 && raw != stableBtn) {
    stableBtn = raw;
    if (stableBtn == LOW) request = true;     // фронт нажатия
  }
}

void setup() {
  pinMode(R, OUTPUT); pinMode(Y, OUTPUT); pinMode(G, OUTPUT);
  pinMode(BTN, INPUT_PULLUP);
  setLights(true, false, false);
}

void loop() {
  readButton();
  unsigned long dur = (state == RED) ? RED_MS : (state == GREEN ? GREEN_MS : YELLOW_MS);
  if (state == GREEN && request) dur = GREEN_MIN;   // сократить зелёный
  if (millis() - entered >= dur) {
    entered = millis();
    if (state == RED)        { state = GREEN;  setLights(false, false, true); }
    else if (state == GREEN) { state = YELLOW; setLights(false, true, false); }
    else                     { state = RED;    setLights(true, false, false); request = false; }
  }
}
```

4. Засеки время цикла секундомером без нажатий и сравни с 10,5 с.
5. Нажми кнопку в начале зелёного и во время красного; сравни поведение.

## Проверка

Ожидай: цикл 10,5 ± 0,1 с; кнопка не пропускается ни в одной фазе; ложных срабатываний от дребезга нет. Светодиоды светятся ровно, ток каждого около 9 мА.

## Если не работает

- **Светодиод не горит.** Проверь полярность, резистор и номер вывода.
- **Все светятся одновременно.** Не учтён сброс остальных: проверь setLights().
- **Кнопка работает «наоборот».** С INPUT_PULLUP нажатая кнопка — LOW; проверь, что кнопка подключена к GND.
- **Цикл длиннее расчёта.** Проверь длительности и что нет delay().
- **Нажатие срабатывает дважды.** Увеличь порог дребезга до 50 мс.
