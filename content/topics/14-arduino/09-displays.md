Рано или поздно проекту нужно показать число: температуру, напряжение, время. Дисплеи бывают разные — от простого семисегментного до графического OLED. Главное — не перепутать выводы и не исчерпать память.

```predict

question: Сколько байт оперативной памяти нужно под экранный буфер OLED 128×64 (1 бит на пиксель)?
options:
  - 256 байт
  - 1024 байта
  - 8192 байта
answer: 1
reveal: 128 · 64 / 8 = 1024 байта — половина RAM ATmega328P (2 КБ). Остальным переменным остаётся 1 КБ.
```

## Какие бывают дисплеи

**Семисегментный индикатор** (4 разряда) требует 12 выводов или регистр 74HC595; цифры включают поочерёдно (мультиплексирование). **LCD1602** показывает 16×2 символа; с модулем PCF8574 управляется по двум проводам I²C. **OLED SSD1306** 128×64 — графический, по I²C, яркий, но съедает 1 КБ RAM.

## Подключение по I²C

Модули I²C подключаются четырьмя проводами: VCC (5 V), GND, SDA (A4), SCL (A5). Подтяжки 4,7 кОм обычно уже стоят на модуле. На одной шине несколько устройств с разными адресами. Если адрес неизвестен, запустите I²C-сканер.

```figure
file: displays/wiring.svg
alt: "Схема подключения. Arduino Uno выводы A4 (SDA) и A5 (SCL) соединены с OLED 128×64 по адресу 0x3C и LCD1602 по адресу 0x27 на одной шине. Подтяжки 4,7 кОм подключены к линиям шины."
caption: "Два I²C-устройства на одной шине Arduino Uno: разные адреса, общие SDA и SCL."
```

```cpp
// LCD1602 по I²C (библиотека LiquidCrystal_I2C)
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);   // адрес, колонки, строки

void setup() {
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("Temp:");
}

void loop() {
  float t = 23.46;                    // значение датчика
  lcd.setCursor(6, 0);
  lcd.print(t, 1);                    // 23.5
  lcd.print(" C ");                   // пробелы стирают хвост
  delay(500);
}
```

```example
title: Какой адрес и сколько устройств
steps:
  - "7-битный адрес I²C занимает диапазон 0x08…0x77: 112 устройств на шине теоретически."
  - "У LCD с PCF8574 адрес 0x27 (перемычки A0–A2 меняют его до 0x20–0x27); у PCF8574A — 0x3F."
  - "OLED SSD1306 имеет 0x3C (иногда 0x3D)."
  - "Эти три устройства не конфликтуют; два LCD с одним адресом не работают на одной шине."
result: 0x27, 0x3C и 0x48 — разные адреса, коллизий нет
```

## Вывод чисел и память

Для чисел с запятой используют `lcd.print(x, 1)`. Остатки старых символов стирают, дописывая пробелы. Графические дисплеи требуют библиотек Adafruit_SSD1306 или U8g2: объект дисплея выделяет буфер в RAM (1 КБ для 128×64), и на ATmega328P остаётся всего 1 КБ на программу, поэтому на Uno выбирают библиотеки, экономящие RAM (U8x8, режим без буфера).
