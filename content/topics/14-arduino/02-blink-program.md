Любая программа Arduino (скетч) начинается с двух функций: `setup()` и `loop()`. Первая запускается один раз при включении, вторая — повторяется бесконечно. Этой структуры достаточно, чтобы заставить мигать светодиод.

```predict

options:
  - 50 %
  - 10 %
  - 90 %
answer: 1
reveal: "Светодиод включён 100 мс из 1000 мс периода: 100/1000 = 10 %. Частота 1 Гц."
```

## Структура программы

Скетч состоит из функций. `void setup()` выполняется однажды, `void loop()` — снова и снова. Выводы настраивают командой `pinMode(номер, режим)`: режим `OUTPUT` — выход, `INPUT` — вход, `INPUT_PULLUP` — вход с подтяжкой. Запись уровня: `digitalWrite(номер, HIGH или LOW)`. Пауза: `delay(мс)`.

```figure
file: blink-program/structure.svg
alt: "Блок-схема. Включение или сброс, затем setup() выполняется один раз, затем loop() повторяется бесконечно, стрелка возвращается на начало loop. Подпись: в setup() настраивают выводы, в loop() основная работа."
caption: "Структура скетча: setup() один раз, loop() бесконечно."
```

```cpp
// Мигание светодиодом на выводе D13
const int LED = 13;          // номер вывода со светодиодом

void setup() {
  pinMode(LED, OUTPUT);      // вывод — выход
}

void loop() {
  digitalWrite(LED, HIGH);   // включить
  delay(250);                // ждать 250 мс
  digitalWrite(LED, LOW);    // выключить
  delay(750);                // ждать 750 мс
}
```

## Частота и скважность

Период мигания равен сумме двух пауз, частота f = 1000 / T(мс). Скважность — доля включённого времени. Чтобы мигание стало вдвое быстрее, сокращают обе паузы вдвое.

## Ошибки компиляции

Компилятор сообщает об ошибках в чёрной области внизу IDE. Типичные: пропущена `;` в конце команды, не закрыта скобка `{ }`, опечатка в имени (`Led` вместо `LED` — регистр важен), неверное число аргументов функции.

```figure
file: blink-program/errors.svg
alt: "Таблица ошибок компиляции. expected ';' before '}' — нет точки с запятой. 'Led' was not declared — опечатка в имени или регистре. expected '}' at end of input — не хватает закрывающей скобки. no matching function for call — неверные аргументы функции."
caption: "Типичные сообщения компилятора и их причины."
```
