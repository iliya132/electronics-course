## Как это устроено

setup выполняется один раз после сброса, loop повторяется. pinMode задаёт режим, digitalWrite — логический уровень, delay останавливает обычное выполнение на указанное время. Ошибка компиляции отличается от ошибки загрузки.

## Модель и единицы

T = tвкл+tвыкл; f=1/T. При длительностях в мс f=1000/(tвкл+tвыкл).

## Проверяем на практике

Сначала меняй одну длительность и сравни период с суммой включённого и выключенного времени. Используй LED_BUILTIN для встроенного индикатора.

До подключения найди общий провод и проверь режим прибора. Изменяй один параметр за раз, записывай расчёт и измерение. Несовпадение сначала проверь по единицам и условиям модели.

```cpp
void setup(){ pinMode(LED_BUILTIN, OUTPUT); }
void loop(){
 digitalWrite(LED_BUILTIN,HIGH); delay(500);
 digitalWrite(LED_BUILTIN,LOW); delay(500);
}
```
