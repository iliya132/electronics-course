Большинство датчиков в учебных проектах — резисторные: NTC (температура), фоторезистор (свет), потенциометр (положение). Все они превращаются в напряжение делителем и читаются analogRead. Остальное — арифметика.

## Код → сопротивление → температура

NTC снизу, 10 кОм сверху, питание 5 В: код = 1024·Rn/(Rn + 10 кОм), откуда **Rn = 10 кОм · код / (1024 − код)**. Температуру находят по B-параметру: **1/T = 1/298,15 + ln(Rn/10 кОм)/3950**, T в кельвинах, затем T − 273,15 в °C.

```cpp
// Температура по NTC 10 кОм (B = 3950), делитель 10 кОм сверху
const int NTC = A0;
const float R_FIX = 10000.0;
const float B = 3950.0, T0 = 298.15, R0 = 10000.0;

float readTemperature() {
  int raw = analogRead(NTC);
  float rn = R_FIX * raw / (1024.0 - raw);          // сопротивление NTC
  float kelvin = 1.0 / (1.0 / T0 + log(rn / R0) / B);
  return kelvin - 273.15;                            // градусы Цельсия
}

void setup() { Serial.begin(9600); }
void loop() { Serial.println(readTemperature(), 1); delay(500); }
```

## Шум и усреднение

Аналоговые отсчёты шумят: младшие разряды «дрожат». Простейший способ — усреднить несколько отсчётов: шум падает в √N раз. Для N = 16 — в 4 раза. Плавный фильтр — экспоненциальное среднее: `y += (x − y) / 8` (каждый новый отсчёт добавляет 1/8 разности).

```cpp
// Среднее по 16 отсчётам
int readAvg(int pin) {
  long sum = 0;
  for (int i = 0; i < 16; i++) sum += analogRead(pin);
  return sum / 16;
}
```

## Фоторезистор и потенциометр

Фоторезистор в делителе с постоянным резистором: код меняется с освещённостью. Для порога включения света достаточно сравнить код с порогом: `if (analogRead(A1) < 300) lightOn();`. Потенциометр даёт код 0…1023 пропорционально положению движка; map() переводит его в любой диапазон (угол, яркость, температуру уставки). Калибровку проводят по эталону: две точки (холод и тепло) позволяют поправить смещение и наклон.

```callout
kind: mistake

```
