## Модель и единицы

Uвых = Uвх·R2/(R1+R2); одинаковые приставки сопротивлений сокращаются. 1 кОм = 1000 Ом.

## Проверяем на практике

Измерь опорные точки, сохрани коэффициенты и проверь промежуточную точку. Для NTC используй фактическую β и не путай верхнее и нижнее плечо.

До подключения найди общий провод и проверь режим прибора. Изменяй один параметр за раз, записывай расчёт и измерение. Несовпадение сначала проверь по единицам и условиям модели.

```cpp
#include <math.h>
float temperature(){
 int code=analogRead(A0);
 if(code<=0 || code>=1023) return NAN;
 float r=10000.0f*code/(1024.0f-code);
 return 1.0f/(1.0f/298.15f+log(r/10000.0f)/3950.0f)-273.15f;
}
void setup(){Serial.begin(9600);}
void loop(){Serial.println(temperature());delay(500);}
```
