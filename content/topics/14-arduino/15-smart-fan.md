## Цель

Соберём «умный» вентилятор: NTC измеряет температуру, Arduino вычисляет скважность ШИМ и управляет вентилятором 12 В через MOSFET. При холоде вентилятор стоит, при тепле растут обороты. Проект собирает всю тему: аналоговый вход, формулу температуры, ШИМ, нагрузку через MOSFET.

## Что понадобится

- Arduino Uno или Nano.
- NTC 10 кОм (B = 3950) и резистор 10 кОм 1 %.
- Вентилятор 12 В (ПК, двухпроводный, 0,1–0,25 А), блок питания 12 В **заводского изготовления**.
- MOSFET IRLZ44N, диод 1N4007, резисторы 100 Ом и 10 кОм.
- Мультиметр, фен или нагретая вода в пакете для проверки (осторожно).

Цены условные, проверяй актуальные.

## Расчёт

- **Кривая:** до 25 °C — вентилятор выключен; включается при ≥ 27 °C со скважностью 30 % и линейно растёт до 100 % при 40 °C. Выключение — при ≤ 25 °C (гистерезис 2 °C).
- **Значение ШИМ:** 30 % → 77 из 255; 100 % → 255; в формуле `map(T·10, 270, 400, 77, 255)`.
- **Среднее напряжение на вентиляторе:** 30 % → 3,6 В (вентилятор может не стартовать) — при включении даём «толчок» 100 % на 0,5 с.
- **Ток:** 0,15 А; потери на MOSFET (Rds 25 мОм): 0,15²·0,025 ≈ **0,56 мВт**.
- **Частота ШИМ:** по умолчанию 490 Гц (слышен писк); таймер 1 при предделителе 1 даёт 31 372 Гц — тихо.
- **Мощность вентилятора:** 12 В · 0,15 А = 1,8 Вт.

## Сборка по шагам

1. Отключи питание. Собери делитель NTC: 5 В → 10 кОм → A0 → NTC → GND.
2. Подключи MOSFET: D9 → резистор 100 Ом → затвор; затвор → 10 кОм → GND; исток → GND; сток → минус вентилятора; плюс вентилятора → +12 В. Диод 1N4007 параллельно вентилятору: катод к +12 В.
3. Земли Arduino и блока 12 В соедини.
4. Загрузи скетч:

```cpp
const int NTC = A0, FAN = 9;
const float R_FIX = 10000.0, B = 3950.0, T0 = 298.15, R0 = 10000.0;
bool fanOn = false;

float readTemperature() {
  long sum = 0;
  for (int i = 0; i < 16; i++) sum += analogRead(NTC);
  float raw = sum / 16.0;
  float rn = R_FIX * raw / (1024.0 - raw);
  return 1.0 / (1.0 / T0 + log(rn / R0) / B) - 273.15;
}

void setup() {
  pinMode(FAN, OUTPUT);
  TCCR1B = (TCCR1B & 0b11111000) | 0x01;   // ШИМ 31 кГц на выводах 9 и 10
  Serial.begin(9600);
}

void loop() {
  float t = readTemperature();
  if (!fanOn && t >= 27.0) { fanOn = true; analogWrite(FAN, 255); delay(500); }   // толчок
  if (fanOn && t <= 25.0)  { fanOn = false; }
  int pwm = 0;
  if (fanOn) pwm = constrain(map((long)(t * 10), 270, 400, 77, 255), 77, 255);
  analogWrite(FAN, pwm);
  Serial.print(t, 1); Serial.print(" C, PWM "); Serial.println(pwm);
  delay(500);
}
```

5. Нагрей NTC (феном издалека или тёплой водой в пакете) и следи за ШИМ в мониторе порта.
6. Измерь напряжение на вентиляторе мультиметром при разных температурах.

## Проверка

Ожидай: вентилятор не крутится ниже 25 °C, включается около 27 °C, обороты растут с температурой; на 31 кГц вентилятор тихий. MOSFET холодный. Мультиметр в режиме постоянного напряжения покажет среднее напряжение (4–12 В), пропорциональное скважности.

## Если не работает

- **Вентилятор не включается.** Проверь затвор, подтяжку, общую землю и диод; измерь напряжение на затворе при ШИМ.
- **Вентилятор свистит.** Включена частота 490 Гц: смени предделитель таймера 1.
- **Вентилятор не стартует на малой скважности.** Увеличь минимум до 40–50 % или используй «толчок».
- **Показания температуры «прыгают».** Усреднение и конденсатор 100 нФ на A0.
- **MOSFET греется.** Не полностью открыт: проверь Uзи (5 В с вывода Arduino) и модель.

