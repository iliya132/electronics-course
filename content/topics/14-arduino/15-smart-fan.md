## Цель

Вентилятор будет ускоряться при нагреве датчика. Arduino вычисляет температуру и задаёт заполнение PWM на внешнем MOSFET-ключе; минимальный рабочий режим должен обеспечивать запуск.

## Что понадобится

- Arduino Uno R3, USB-кабель данных
- Макетная плата и перемычки
- NTC-делитель 10 кОм/10 кОм
- Готовый MOSFET-драйвер с защитой и вентилятор 5 В
- Отдельный источник вентилятора с общей землёй

Бюджет: сначала используй детали своего набора. Для планирования можно заложить 1500–5000 ₽ без измерительных приборов; это условный резерв, актуальные цены проверяй перед покупкой.

## Сборка по шагам

1. Собери NTC-делитель на A0 как в термометре.
2. Подключи D9 к входу проверенного MOSFET-драйвера, GND к общему проводу.
3. Подключи вентилятор и отдельный источник по документации драйвера.
4. Загрузи код; проверь пуск, нагрев и реакцию на обрыв датчика.

```cpp
#include <math.h>
float temperature(){
 int code=analogRead(A0);
 if(code<=0 || code>=1023) return NAN;
 float r=10000.0f*code/(1024.0f-code);
 return 1.0f/(1.0f/298.15f+log(r/10000.0f)/3950.0f)-273.15f;
}
void setup(){pinMode(9,OUTPUT);analogWrite(9,0);Serial.begin(9600);}
void loop(){
 float t=temperature();int duty;
 if(isnan(t))duty=255; // При неисправном датчике охлаждение включено.
 else if(t<25)duty=0;
 else duty=constrain((int)(100+(t-25)*10),100,255);
 analogWrite(9,duty);Serial.println(t);delay(100);
}
```

## Проверка

Ниже 25 °C команда нулевая; выше задана нижняя граница 100/255≈39,2 %. Реальную минимальную команду запуска подбери измерением. При ошибке датчика программа выдаёт 255.

## Если не работает

- Неправильно подключены выводы или общий GND.
- Не совпадает адрес, тип модуля или библиотека.
- Источник проседает под нагрузкой.
```callout
kind: mistake
text: >-
  Сломанный датчик всегда должен выключать охлаждение. Для надёжного охлаждения нужна обработка
  неисправности датчика.
```
