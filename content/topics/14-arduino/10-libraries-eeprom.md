Чужой код экономит часы. Библиотека — готовый набор функций для датчика, дисплея или протокола. А EEPROM — «блокнот» МК, где можно хранить настройки при выключенном питании. Оба инструмента просты — и оба имеют подводные камни.

## Библиотеки

Установка: **Sketch → Include Library → Manage Libraries**, найти по имени, нажать Install. В коде подключают `#include <Имя.h>`, затем создают объект и вызывают методы. Главное — **примеры** (File → Examples → имя библиотеки): рабочий скетч с комментариями. Читай описание (README) и версию: библиотеки для разных плат бывают несовместимы.

## EEPROM

**EEPROM** — энергонезависимая память для небольших данных: 1 КБ у ATmega328P. Используют библиотеку `EEPROM.h`: `EEPROM.read(адрес)`, `EEPROM.update(адрес, байт)` (пишет, только если значение изменилось), `EEPROM.put/get` для типов больше байта.

```cpp
#include <EEPROM.h>

const int ADDR = 0;           // адрес настройки (4 байта под float)
float setpoint = 25.0;        // уставка по умолчанию

void setup() {
  Serial.begin(9600);
  float saved;
  EEPROM.get(ADDR, saved);    // читаем сохранённую уставку
  if (!isnan(saved) && saved > 5 && saved < 60) setpoint = saved;   // проверка разумности
  Serial.print("Уставка: "); Serial.println(setpoint);
}

void loop() {
  // изменили уставку кнопками — сохраняем ТОЛЬКО при изменении
  float newValue = setpoint;                // здесь расчёт нового значения
  if (newValue != setpoint) { setpoint = newValue; EEPROM.put(ADDR, setpoint); }
}
```

## Лучшие практики

Пиши в EEPROM только при **изменении**, а не по таймеру. Для частых записей используй «вращение» по ячейкам или внешнюю память (FRAM, SD). Проверяй прочитанное значение на разумность (пустая EEPROM читается как 0xFF).

```callout
kind: mistake
text: "Пишут в EEPROM в каждом проходе loop() «на всякий случай». За несколько минут ячейка исчерпывает ресурс и начинает отдавать неверные данные. Пиши только при изменении значения: EEPROM.update() или явное сравнение."
```

```callout
kind: board
text: "EEPROM внутри ATmega328P отдельного корпуса не имеет; внешние 24LC256 (I²C, 32 КБ) — маленькие 8-выводные микросхемы на платах часов и датчиков. Для частых записей берут FRAM (практически безлимитный ресурс)."
```
