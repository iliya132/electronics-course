## Цель

Проверим профиль заряда готовым модулем без самостоятельной сборки зарядной микросхемы. Наблюдаем переход от ограничения тока к ограничению напряжения и нагрев.

## Что понадобится

- Защищённая совместимая Li-ion ячейка в держателе
- Проверенный TP4056-модуль с защитой и током, допустимым для ячейки
- Источник USB 5 В, мультиметр с исправным токовым предохранителем

Бюджет: сначала используй детали своего набора. Для планирования можно заложить 500–1500 ₽ без измерительных приборов; это условный резерв, актуальные цены проверяй перед покупкой.

## Сборка по шагам

1. Без питания проверь маркировки B+/B−, OUT+/OUT− и входа модуля.
2. Подключи держатель строго к B+/B−; свободную нагрузку к OUT пока не подключай.
3. Для измерения тока батареи включи амперметр последовательно, начав с подходящего предела; проверь номинал предохранителя.
4. Подай USB 5 В, наблюдай ток и температуру. Напряжение батареи измеряй отдельным V-режимом параллельно.
5. Запиши последовательность измерений и отметь уменьшение тока в конце; отключи вход перед изменением проводки.
## Проверка

Для модельного закона Iзар(мА)=1200/Rprog(кОм), Rprog=2,4 кОм соответствует примерно 500 мА. Реальный ток может снижаться при нагреве. Конечное напряжение берут только из документации конкретного контроллера и ячейки; для варианта 4,2 В не допускай превышения его спецификации.

## Если не работает

- Перепутаны силовые контакты батареи и защищённого выхода.
- Источник USB или кабель не обеспечивает нужный ток.
- Нагрузка мешает критерию завершения заряда.
```callout
kind: mistake
text: >-
  Заряд можно оставлять без наблюдения рядом с горючими материалами. Для опыта нужна совместимая
  защищённая ячейка и проверенный зарядный модуль.
```

