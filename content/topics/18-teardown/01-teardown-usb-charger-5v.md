Рассматриваем только учебную функциональную схему изолированного источника. Входной выпрямитель и накопительный конденсатор находятся на опасной первичной стороне. Ключ управляет передачей энергии через трансформатор, выходной диод заряжает низковольтный фильтр. TL431 сравнивает выход с опорой и через оптопару передаёт обратную связь через изоляционный барьер. Схема не задаёт номиналы для самостоятельной сборки сетевого устройства.

```widget
name: board-hotspots
params:
  nodes:
    - name: Входной мост
      role: Выпрямляет входной переменный ток
      lesson: diode-bridge
      explanation: Работает на первичной стороне до накопительного конденсатора.
    - name: Накопительный конденсатор
      role: Сглаживает напряжение первичной шины
      lesson: capacitor-basics
      explanation: Может сохранять опасный заряд после отключения.
    - name: Ключ и контроллер
      role: Дозируют передачу энергии импульсами
      lesson: buck
      explanation: Контроллер меняет импульсы по сигналу обратной связи.
    - name: Трансформатор
      role: Передаёт энергию через изоляционный барьер
      lesson: transformer
      explanation: Изоляция обеспечивается конструкцией и расстояниями, не условным значком.
    - name: Выходной диод
      role: Выпрямляет импульсы вторичной обмотки
      lesson: diode-basics
      explanation: Пропускает ток к выходному фильтру в нужную фазу.
    - name: TL431 и оптопара
      role: Передают ошибку выходного напряжения обратно к контроллеру
      lesson: optocouplers
      explanation: TL431 управляет током LED оптопары, сохраняя электрическое разделение сторон.
caption: Выбери узел и его назначение.
```
