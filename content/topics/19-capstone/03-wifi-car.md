## Цель

ТЗ: робот движется, пока на телефоне удерживается кнопка, и останавливается не позднее чем через 0,5 с после последней команды. ESP32 работает точкой доступа, TB6612 управляет двумя моторами. Силовая ветвь VM и питание логики разделены по проводам, но земли объединены. Выбирай моторы по пусковому току, а не по току вращения без нагрузки.

## Что понадобится

- ESP32 и TB6612FNG, два низковольтных мотора с допустимым пусковым током
- Шасси, выключатель, защищённое низковольтное питание
- 100 нФ у питания логики и VM, буфер 470 мкФ подходящего напряжения у VM
- Отдельный стабилизатор питания ESP32, подтяжка STBY 10 кОм к GND

Бюджет: сначала используй детали своего набора. Для планирования можно заложить 1500–5000 ₽ без измерительных приборов; это условный резерв, актуальные цены проверяй перед покупкой.

## Сборка по шагам

1. VCC драйвера к 3,3 В, VM к моторному источнику; земли соединить коротко. Моторы к AO1/AO2 и BO1/BO2.
2. Подключи AIN1=26,AIN2=27,BIN1=32,BIN2=33,PWMA=25,PWMB=14,STBY=13.
3. Поставь буферный конденсатор у VM с верной полярностью; не проводи моторный ток через макетную землю ESP32.
4. Код рассчитан на Arduino-ESP32 3.x. Смени пароль точки доступа, загрузи скетч, подключись к CourseRobot и открой 192.168.4.1.
5. С поднятыми колёсами проверь направления, отпускание кнопки и отключение Wi-Fi. Затем запускай на свободном полу с доступным выключателем.

```cpp
#include <WiFi.h>
#include <WebServer.h>
WebServer server(80);
const int A1=26,A2=27,B1=32,B2=33,PA=25,PB=14,STBY=13;
unsigned long lastCommand=0;bool moving=false;
void stopMotors(){digitalWrite(STBY,LOW);ledcWrite(PA,0);ledcWrite(PB,0);moving=false;}
void drive(int left,int right){
 // Сначала отключить мост при изменении направления.
 stopMotors();
 digitalWrite(A1,left>0);digitalWrite(A2,left<0);digitalWrite(B1,right>0);digitalWrite(B2,right<0);
 ledcWrite(PA,abs(left));ledcWrite(PB,abs(right));
 digitalWrite(STBY,HIGH);lastCommand=millis();moving=true;
}
void setup(){
 pinMode(STBY,OUTPUT);digitalWrite(STBY,LOW);
 for(int p:{A1,A2,B1,B2})pinMode(p,OUTPUT);
 ledcAttach(PA,10000,8);ledcAttach(PB,10000,8);
 WiFi.mode(WIFI_AP);WiFi.softAP("CourseRobot","change-me-123");
 server.on("/",HTTP_GET,[](){
  server.send(200,"text/html; charset=utf-8",R"HTML(
<meta name="viewport" content="width=device-width">
<h1>Учебный робот</h1><p>Удерживай кнопку. Отпускание останавливает.</p>
<button data-c="f">Вперёд</button><button data-c="b">Назад</button>
<button data-c="l">Влево</button><button data-c="r">Вправо</button><button data-c="s">Стоп</button>
<script>
let timer;const send=c=>fetch('/cmd?c='+c,{method:'POST'});
function stop(){clearInterval(timer);send('s');}
document.querySelectorAll('button').forEach(b=>{
 b.onpointerdown=e=>{stop();b.setPointerCapture(e.pointerId);send(b.dataset.c);timer=setInterval(()=>send(b.dataset.c),150);};
 b.onpointerup=stop;b.onpointercancel=stop;
});document.onvisibilitychange=()=>{if(document.hidden)stop();};
</script>)HTML");
 });
 server.on("/cmd",HTTP_POST,[](){
  String c=server.arg("c");
  if(c=="f")drive(120,120);else if(c=="b")drive(-120,-120);
  else if(c=="l")drive(-100,100);else if(c=="r")drive(100,-100);
  else stopMotors();server.send(200,"text/plain","ok");
 });server.begin();
}
void loop(){server.handleClient();if(moving && (unsigned long)(millis()-lastCommand)>500)stopMotors();}
```

## Проверка

Если каждый мотор потребляет 0,2 А в движении, но 1 А при пуске, два мотора требуют до 2 А только на силовой ветви. При импульсе 0,5 А в течение 1 мс на 470 мкФ идеальная просадка 1,064 В: конденсатор не заменяет источник достаточной мощности. Измерь задержку останова при отключении телефона.

## Если не работает

- Сброс ESP32 при старте: раздельные силовые провода, источник и буфер; проверь общую землю.
- Один мотор назад: переставь его провода при выключенном питании или измени знак в коде.
- Драйвер греется: измерь пусковой/стопорный ток кратким безопасным методом; выбери более мощный драйвер.
- Тайм-аут программный; аппаратный выключатель остаётся обязательным.
```callout

  должна обеспечиваться тайм-аутом на самом роботе.
```
