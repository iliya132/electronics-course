## Цель

**Техническое задание.** Двухколёсный робот, управляемый с телефона по Wi-Fi: вперёд, назад, влево, вправо, стоп; скорость регулируется ползунком. Питание — две ячейки 18650 (2S, 7,4 В) с защитой. Время работы не менее 2 часов. Проект собирает драйвер моторов, питание, Wi-Fi и расчёты.

## Что понадобится

- ESP32 DevKit, драйвер TB6612FNG (модуль), два мотор-редуктора N20 6 В, шасси и колёса.
- Две ячейки 18650 с держателем 2S и BMS 2S; понижающий модуль 7,4 → 5 В (1–2 А).
- Конденсаторы 470 мкФ (питание моторов) и 100 нФ на каждый мотор, выключатель питания, предохранитель PTC 2 А.
- Провода, макетная плата или самодельная плата.
- При отладке вместо аккумуляторов: лабораторный блок питания WANPTEK TPS3010 (7,40 В, предел тока 2 А), осциллограф Rigol DHO804 и мультиметр Rigol DM858E.

## Расчёт

- **Моторы:** ход 0,25–0,3 А каждый, стопор 0,8–1,5 А; по два: ход 0,6 А.
- **ESP32:** 0,12 А (пик 0,4 А) через понижающий модуль на 5 В: потребление от батареи ≈ 5·0,12/(0,9·7,4) ≈ 0,09 А.
- **Итого ход:** ≈ 0,69 А от 7,4 В; время работы 2600/0,69 ≈ 3,8 ч (идеально), реально 2,5–3 ч — цель выполнена.
- **Драйвер:** 1,2 А на канал ≥ 0,3 А хода и достаточно для кратковременного стопора; потери на мосту 0,5 Ом·0,3² ≈ 45 мВт.
- **Скорость:** моторы 6 В, батарея 7,4 В: ограничение ШИМ 80 % → ≈ 5,9 В.
- **Буфер:** конденсатор 470 мкФ на VM: заряд при просадке 0,5 А за 10 мс: ΔU = I·t/C = 0,5·0,01/470·10⁻⁶ ≈ 10,6 В — конденсатор сглаживает только короткие импульсы; поэтому питание логики отдельное.

## Сборка по шагам

1. Отключи питание. Батарея → BMS → выключатель → PTC → шина «7,4 В». На шину: конденсатор 470 мкФ, VM драйвера, вход понижающего модуля (выставь 5,0 В до подключения ESP32!).
2. ESP32: питание 5 В на вывод 5V от модуля; земли общие. Драйвер TB6612: VCC 3,3 В от ESP32, STBY на 3,3 В.
3. Сигналы: PWMA — GPIO25, AIN1 — GPIO26, AIN2 — GPIO27; PWMB — GPIO14, BIN1 — GPIO12 (осторожно: strapping!), лучше BIN1 — GPIO32, BIN2 — GPIO33.
4. Конденсаторы 100 нФ на выводы каждого мотора.
5. Скетч (точка доступа и управление):

```cpp
#include <WiFi.h>
#include <WebServer.h>

const int PWMA = 25, AIN1 = 26, AIN2 = 27, PWMB = 14, BIN1 = 32, BIN2 = 33;
WebServer server(80);
int speedPct = 60;                           // 0–80 %

void drive(int l, int r) {                   // -100..100
  auto set = [](int pwmPin, int in1, int in2, int v) {
    int duty = map(abs(v), 0, 100, 0, 204);  // 80 % от 255
    digitalWrite(in1, v > 0); digitalWrite(in2, v < 0);
    ledcWrite(pwmPin, duty);
  };
  set(PWMA, AIN1, AIN2, l);
  set(PWMB, BIN1, BIN2, r);
}

const char PAGE[] PROGMEM = R"HTML(<!doctype html><meta name=viewport content="width=device-width">
<style>button{font-size:28px;margin:6px;padding:14px 22px}</style>
<h2>Робот</h2>
<button onclick="c('f')">&uarr;</button><br>
<button onclick="c('l')">&larr;</button><button onclick="c('s')">■</button><button onclick="c('r')">&rarr;</button><br>
<button onclick="c('b')">&darr;</button><br>
<input type=range min=20 max=80 value=60 oninput="fetch('/v?s='+this.value)">
<script>function c(x){fetch('/c?d='+x)}</script>)HTML";

void setup() {
  int pins[] = {AIN1, AIN2, BIN1, BIN2};
  for (int p : pins) pinMode(p, OUTPUT);
  ledcAttach(PWMA, 20000, 8);
  ledcAttach(PWMB, 20000, 8);
  WiFi.softAP("robot", "12345678");
  server.on("/", []() { server.send(200, "text/html", PAGE); });
  server.on("/c", []() {
    String d = server.arg("d");
    int s = speedPct;
    if (d == "f") drive(s, s); else if (d == "b") drive(-s, -s);
    else if (d == "l") drive(-s, s); else if (d == "r") drive(s, -s); else drive(0, 0);
    server.send(200, "text/plain", "ok");
  });
  server.on("/v", []() { speedPct = constrain(server.arg("s").toInt(), 20, 80); server.send(200, "text/plain", "ok"); });
  server.begin();
}

unsigned long lastCmd = 0;
void loop() { server.handleClient(); }
```

## Проверка

Ожидай: страница открывается по 192.168.4.1; робот реагирует на кнопки за доли секунды; ESP32 не перезагружается при разгоне и торможении; напряжение 5 В на ESP32 стабильно (±0,1 В); моторы и драйвер тёплые, но не горячие. При потере связи с телефоном робот должен остановиться: добавь таймаут команды 1 с (идея развития обязательна для безопасности).

## Если не работает

- **Моторы не крутятся.** STBY должен быть в 1; проверь VM и земли, IN1/IN2.
- **Крутятся в разные стороны.** Поменяй провода мотора или инвертируй направление в коде.
- **ESP32 перезагружается.** Отдельное питание логики, конденсаторы, проверка 5 В.
- **Робот не останавливается.** Нет таймаута команды: добавь остановку, если команды нет 1 с.
- **Греется драйвер.** Стопор колёс или ток выше 1,2 А: проверь механику.


## Идеи развития

- Добавь автостоп при потере связи (таймаут 1 с) и датчик препятствий.
- Измеряй напряжение батареи и отключай моторы при 6,4 В (3,2 В на ячейку).
- Добавь датчик тока (INA219) и сигнализацию стопора.
- Перенеси схему на печатную плату.
