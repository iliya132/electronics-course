## Цель

ТЗ: разработать в KiCad плату датчика температуры на ESP32-WROOM с USB-C питанием, USB-UART и BME280. Заказ необязателен: результатом служат схема, PCB, BOM и проверенный комплект Gerber. Используем изученный классический модуль, чтобы повторно применить код метеостанции; переход на C3 требует новой проверки выводов, USB и загрузки.

## Что понадобится

- KiCad и официальные даташиты точных заказных кодов
- ESP32-WROOM-модуль, BME280 или согласованный разъём датчика
- USB-C, два отдельных Rd 5,1 кОм, USB-UART с логикой 3,3 В
- LDO 3,3 В с достаточным током, рекомендованные входной/выходной конденсаторы
- EN/BOOT, развязка, индикатор с резистором, контрольные точки

Бюджет: сначала используй детали своего набора. Для планирования можно заложить 1500–5000 ₽ без измерительных приборов; это условный резерв, актуальные цены проверяй перед покупкой.

## Сборка по шагам

1. Составь таблицу цепей: VBUS,3V3,GND,SDA21,SCL22,UART TX/RX,EN,GPIO0. Назначь только проверенные выводы.
2. Для выбранного LDO выполни тепловой расчёт и проверь устойчивость с конкретными C/ESR. Rd USB-C подключаются отдельно CC1–GND и CC2–GND.
3. Нарисуй схему по reference design каждого компонента, назначь корпуса по даташитам и проверь соответствие выводов.
4. Размести модуль у края с требуемым keepout, LDO и развязку близко к потребителям; сохрани сплошной возврат под сигналами.
5. Запусти ERC/DRC, распечатай 1:1, проверь Gerber/сверловку/BOM и схему коллегой или отдельным проходом.
6. При изготовлении первое включение делай от источника с ограничением тока. Сначала проверь питание, затем UART-загрузку и код датчика.

```cpp
#include <WiFi.h>
#include <WebServer.h>
#include <Wire.h>
#include <Adafruit_BME280.h>
Adafruit_BME280 bme;
bool beginSensor(){Wire.begin(21,22);return bme.begin(0x76)||bme.begin(0x77);}
WebServer server(80);
const char* ssid="YOUR_WIFI";
const char* password="YOUR_PASSWORD";
bool sensorOK=false;
void setup(){
 Serial.begin(115200);sensorOK=beginSensor();
 WiFi.mode(WIFI_STA);WiFi.begin(ssid,password);
 unsigned long start=millis();
 while(WiFi.status()!=WL_CONNECTED && millis()-start<15000)delay(100);
 if(WiFi.status()!=WL_CONNECTED){Serial.println("WiFi failed");return;}
 Serial.println(WiFi.localIP());
 server.on("/",HTTP_GET,[](){
  server.send(200,"text/html; charset=utf-8","<meta charset='utf-8'><h1>Датчик ESP32</h1><pre id='v'></pre><script>setInterval(()=>fetch('/data').then(r=>r.text()).then(t=>document.getElementById('v').textContent=t),2000)</script>");
 });
 server.on("/data",HTTP_GET,[](){
  if(!sensorOK){server.send(503,"application/json","{"error":"sensor"}");return;}
  String json="{"temperature":"+String(bme.readTemperature(),2)+","humidity":"+String(bme.readHumidity(),2)+"}";
  server.send(200,"application/json",json);
 });server.begin();
}
void loop(){server.handleClient();}
```

## Проверка

При 5→3,3 В и 0,25 А LDO рассеивает 0,425 Вт. Если эффективное θJA=100 °C/Вт, оценочный подъём 42,5 °C; фактический θJA зависит от платы. В BOM должны быть полные заказные коды и номиналы, на плате — обозначения, полярность и тестовые точки. Скетч проекта web-sensor-server используется без смены GPIO, если таблица цепей совпадает.

## Если не работает

- Несовпадение футпринта: сравни размерный чертёж, номера и вид сверху/снизу.
- Нет загрузки: проверь 3V3, EN, BOOT, перекрёст UART и уровни моста.
- Датчик не виден: адрес, подтяжки, SDA/SCL и питание.
- Нестабильный Wi-Fi: питание при пиках, антенная зона и окружающий металл.
```callout
kind: mistake

  ошибки, но не подтверждают работоспособность устройства.
```
