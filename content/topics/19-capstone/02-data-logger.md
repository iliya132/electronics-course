## Цель

ТЗ: раз в секунду сохранять время, напряжение и ток низковольтной нагрузки в CSV на SD и показывать текущие значения на OLED. INA219 включается в разрыв плюсового провода: VIN+ к источнику, VIN− к нагрузке. Земля общая. Начальный учебный диапазон 0–12 В и до 0,5 А выбираем с учётом конкретного шунта и калибровки модуля.

## Что понадобится

- ESP32, INA219, RTC DS3231, OLED SSD1306 128×64
- SD-модуль с логикой 3,3 В и карта FAT32
- Нагрузочные резисторы подходящей мощности, мультиметр
- Библиотеки Adafruit INA219/GFX/SSD1306, RTClib; SPI/SD/Wire из ядра

Бюджет: сначала используй детали своего набора. Для планирования можно заложить 1500–5000 ₽ без измерительных приборов; это условный резерв, актуальные цены проверяй перед покупкой.

## Сборка по шагам

1. Все I²C-модули подключи к SDA21/SCL22, общей земле и допустимому питанию. Подтяжки только к 3,3 В; проверь адреса 0x40,0x68,0x3C.
2. SD: SCK18,MISO19,MOSI23,CS5; следи за boot-уровнем GPIO5 и не используй модуль, тянущий его неверно.
3. Соедини токовый путь VIN+→шунт→VIN− последовательно с нагрузкой. Проверь пределы модуля до подачи напряжения.
4. Установи RTC один раз примером RTClib ds3231, затем отключи автоматическую установку времени при каждом запуске.
5. Загрузи код, выполни калибровку коэффициента currentScale, проверь CSV и OLED.

[Скачать скетч .ino](/examples/data-logger/data-logger.ino)

```cpp
#include <Wire.h>
#include <SPI.h>
#include <SD.h>
#include <Adafruit_INA219.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <RTClib.h>
Adafruit_INA219 ina;
Adafruit_SSD1306 oled(128,64,&Wire,-1);
RTC_DS3231 rtc;
bool ready=false; unsigned long last=0;
const float currentScale=1.0; // После сравнения с эталоном.
void setup(){
 Serial.begin(115200);Wire.begin(21,22);SPI.begin(18,19,23,5);
 bool a=ina.begin(), b=rtc.begin(), c=SD.begin(5);
 bool d=oled.begin(SSD1306_SWITCHCAPVCC,0x3C);
 if(b && rtc.lostPower()){
  Serial.println("Set RTC time before recording");return;
 }
 ready=a&&b&&c&&d;
 Serial.println(ready?"ready":"check modules");
}
void loop(){
 if(!ready || (unsigned long)(millis()-last)<1000)return;last=millis();
 float volts=ina.getBusVoltage_V()+ina.getShuntVoltage_mV()/1000.0;
 float mA=ina.getCurrent_mA()*currentScale;DateTime now=rtc.now();
 File f=SD.open("/measure.csv",FILE_APPEND);
 if(!f){Serial.println("SD open failed");return;}
 f.print(now.timestamp());f.print(',');f.print(volts,3);f.print(',');f.println(mA,2);f.close();
 oled.clearDisplay();oled.setTextColor(SSD1306_WHITE);oled.setTextSize(1);
 oled.setCursor(0,0);oled.print(volts,3);oled.println(" V");oled.print(mA,2);oled.println(" mA");oled.display();
}
```

## Проверка

Для нагрузки 100 Ом при 5 В ожидаем около 50 мА и 0,25 Вт; возьми резистор не менее 0,5 Вт. При 40 байтах на строку за сутки при 1 Гц получится 3 456 000 байт плюс файловые накладные расходы. Проверь 60 последовательных временных меток и корректное открытие CSV.

## Если не работает

- Отрицательный ток: проверь направление VIN+/VIN−.
- RTC lostPower: установи время и проверь элемент резервного питания; не заряжай обычную CR2032 платой с зарядной цепью.
- Ошибки SD: уровни, питание при записи, формат, CS.
- Смещение нуля не исправляется только масштабным коэффициентом: при необходимости калибруй отдельно.
```callout
kind: mistake
text: >-
  INA219 измеряет ток без включения шунта в токовый путь. Точность зависит от шунта, калибровки,
  проводов и выбранного диапазона.
```
