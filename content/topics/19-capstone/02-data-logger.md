## Цель

**Техническое задание.** Регистратор напряжения, тока, мощности и энергии для цепей до 26 В и 3 А: раз в секунду показывает значения на LCD и записывает строку в CSV на SD-карту с отметкой реального времени. Точность тока лучше ±2 % после калибровки. Проект объединяет шунт, I²C, SPI и аккуратную работу с памятью.

## Что понадобится

- Arduino Nano, INA219 (шунт 0,1 Ом), часы DS3231, LCD1602 с I²C, модуль SD (SPI), карта FAT32.
- Библиотеки Adafruit_INA219, RTClib, LiquidCrystal_I2C, SD.
- Эталонный мультиметр, нагрузка: резисторы 10 Ом и 3,3 Ом (5–10 Вт), источник 5 В.

Цены условные, проверяй актуальные.

## Расчёт

- **Адреса I²C:** INA219 — 0x40, DS3231 — 0x68, LCD — 0x27: коллизий нет.
- **Диапазон:** шунт 0,1 Ом, ±320 мВ → до 3,2 А; шаг 0,1 мА.
- **Запись:** строка ≈ «2025-05-01 12:00:00,5.02,498.3,2.50» ≈ 36 байт; раз в секунду 86 400 строк в сутки ≈ **3,1 МБ**: карта 2 ГБ хватит на ≈ 640 суток.
- **Энергия:** E(Вт·ч) += P(Вт)·Δt/3600; при 5 В и 0,5 А — 2,5 Вт ≈ 60 Вт·ч за сутки.
- **Погрешность:** шунт 1 % + усиление 0,5 % ≈ 1,1 % (корень из суммы квадратов), смещение ±1 мА; на токе 0,5 А общая ошибка ≈ ±7,5 мА (1,5 %).
- **RAM Nano:** библиотеки SD + LCD + RTC ≈ 1 КБ, остаётся ≈ 1 КБ.

## Сборка по шагам

1. Отключи питание. I²C: INA219, DS3231, LCD параллельно на A4 (SDA) и A5 (SCL), питание 5 В. SD: D13 SCK, D12 MISO, D11 MOSI, D10 CS.
2. Силовая цепь: «+» источника → VIN+ INA219, VIN− → нагрузка → общий минус.
3. Скетч:

```cpp
#include <Wire.h>
#include <SPI.h>
#include <SD.h>
#include <Adafruit_INA219.h>
#include <RTClib.h>
#include <LiquidCrystal_I2C.h>

Adafruit_INA219 ina;
RTC_DS3231 rtc;
LiquidCrystal_I2C lcd(0x27, 16, 2);
float energyWh = 0;
unsigned long last = 0;
const float K = 0.985, B0 = -2.4;      // калибровка тока (мА): подставь свои

void setup() {
  Serial.begin(9600);
  Wire.begin();
  ina.begin();
  rtc.begin();
  lcd.init(); lcd.backlight();
  if (!SD.begin(10)) { lcd.print("SD error"); while (true) {} }
  File f = SD.open("LOG.CSV", FILE_WRITE);
  if (f) { f.println("time,V,mA,mW,Wh"); f.close(); }
}

void loop() {
  if (millis() - last >= 1000) {
    float dt = (millis() - last) / 3600000.0;
    last = millis();
    float v = ina.getBusVoltage_V();
    float mA = K * ina.getCurrent_mA() + B0;
    float mW = v * mA;
    energyWh += mW / 1000.0 * dt;
    DateTime t = rtc.now();
    char ts[20];
    snprintf(ts, sizeof(ts), "%04d-%02d-%02d %02d:%02d:%02d", t.year(), t.month(), t.day(), t.hour(), t.minute(), t.second());
    File f = SD.open("LOG.CSV", FILE_WRITE);
    if (f) {
      f.print(ts); f.print(','); f.print(v, 2); f.print(','); f.print(mA, 1); f.print(',');
      f.print(mW, 0); f.print(','); f.println(energyWh, 3); f.close();
    }
    lcd.setCursor(0, 0); lcd.print(v, 2); lcd.print("V "); lcd.print(mA, 0); lcd.print("mA   ");
    lcd.setCursor(0, 1); lcd.print(mW / 1000.0, 2); lcd.print("W "); lcd.print(energyWh, 2); lcd.print("Wh ");
  }
}
```

4. Установи время DS3231 (скетч из примеров RTClib) и убедись, что строки пишутся.
5. Выполни калибровку по двум токам (нагрузки 10 Ом и 3,3 Ом), впиши K и B0.
6. Запусти запись на час и проверь энергию: P·t.

| Нагрузка | I эталон, мА | I логгера до калибровки | После |
|---|---|---|---|
| 10 Ом, 5 В | | | |
| 3,3 Ом, 5 В | | | |

## Проверка

Ожидай: строка в LOG.CSV каждую секунду с правильным временем; ошибка тока после калибровки ≤ 2 %; энергия за час при 2,5 Вт ≈ 2,5 Вт·ч; LCD показывает значения без «хвостов». RAM Nano не переполняется (проверь отчёт компиляции: свободно ≥ 300 байт).

## Если не работает

- **«SD error».** Линии SPI, питание 5 В модуля, формат FAT32, CS на D10.
- **Время сбрасывается.** Нет батарейки CR2032 в DS3231.
- **LCD пуст.** Адрес 0x27/0x3F, контраст.
- **Ток отрицательный.** Перепутаны VIN+ и VIN−.
- **Нехватка памяти.** Убери лишние строки Serial, используй F(), не добавляй OLED.

```callout
kind: mistake

```

## Идеи развития

- Добавь второй канал INA219 (адрес 0x41) и измеряй вход и выход преобразователя.
- Построй график P(t) на компьютере и найди энергию за цикл заряда.
- Добавь срабатывание реле по превышению тока.
- Сравни результат с заводским измерителем мощности.
