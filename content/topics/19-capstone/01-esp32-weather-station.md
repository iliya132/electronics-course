## Цель

**Техническое задание.** Автономная метеостанция: раз в 10 минут измеряет температуру, влажность, давление и напряжение батареи, отправляет в MQTT и засыпает. Питание от Li-ion 18650 с зарядкой по USB. Цель: не менее 100 суток от одной ячейки. Это итоговый проект: все блоки из курса — питание, сон, датчик, сеть — собираются в одно устройство.

## Что понадобится

- ESP32 DevKit (для отладки) или модуль ESP32-WROOM с отдельным LDO; BME280.
- Защищённая ячейка 18650 (2600 мА·ч) и держатель, модуль TP4056 с защитой (DW01A + FS8205A).
- LDO AP2112K-3.3 (или готовый модуль), конденсаторы 10 мкФ и 100 нФ, два резистора 100 кОм.
- Брокер Mosquitto в сети (из проекта MQTT), мультиметр или INA219.

Цены условные, проверяй актуальные.

## Расчёт

- **Бюджет активной фазы:** Wi-Fi и измерение ≈ 4 с при среднем токе ≈ 100 мА (пик 350 мА).
- **Ток сна:** чип 10 мкА + LDO 55 мкА + делитель батареи 3,7 В / 200 кОм ≈ 18,5 мкА + BME280 0,1 мкА ≈ **85 мкА**.
- **Средний ток:** (100 · 4 + 0,085 · 596) / 600 ≈ **0,75 мА**.
- **Срок:** 2600 / 0,75 ≈ 3460 ч ≈ 144 суток идеально; с поправкой 0,75 ≈ **108 суток** — цель выполнена.
- **LDO:** от ячейки 3,0–4,2 В; AP2112K при токе 350 мА держит 3,3 В до входа ≈ 3,5 В; ниже выход слегка проседает (допустимо для ESP32 до 3,0 В).
- **Делитель батареи:** 4,2 В → 2,1 В на входе (в диапазоне ADC1 при 11 дБ); погрешность 1 % резисторов ≈ ±40 мВ.

## Сборка по шагам

1. Собери питание: USB → TP4056 с защитой → ячейка; OUT+ → AP2112K → 3V3 (конденсаторы 10 мкФ на входе и выходе, 100 нФ у модуля). Нагрузку только на OUT, не на B.
2. BME280: SDA — GPIO21, SCL — GPIO22. Делитель 100 кОм/100 кОм от 3V3-батареи (до LDO: от OUT+) на GPIO34, 100 нФ на землю.
3. Загрузи скетч:

```cpp
#include <WiFi.h>
#include <PubSubClient.h>
#include <Wire.h>
#include <Adafruit_BME280.h>
#include <esp_sleep.h>

const char* SSID = "имя_сети";
const char* PASS = "пароль_сети";
const char* BROKER = "192.168.1.10";
const uint64_t SLEEP_US = 600ULL * 1000000ULL;   // 10 минут

Adafruit_BME280 bme;
WiFiClient net;
PubSubClient mqtt(net);

void sendValue(const char* topic, float v, int d) {
  char buf[16]; dtostrf(v, 0, d, buf); mqtt.publish(topic, buf);
}

void setup() {
  Wire.begin(21, 22);
  bme.begin(0x76);
  analogSetPinAttenuation(34, ADC_11db);
  float t = bme.readTemperature(), h = bme.readHumidity(), p = bme.readPressure() / 100.0F;
  long sum = 0; for (int i = 0; i < 16; i++) sum += analogReadMilliVolts(34);
  float vbat = 2.0 * sum / 16.0 / 1000.0;            // делитель 1:2

  WiFi.mode(WIFI_STA);
  WiFi.begin(SSID, PASS);
  unsigned long t0 = millis();
  while (WiFi.status() != WL_CONNECTED && millis() - t0 < 8000) delay(50);
  if (WiFi.status() == WL_CONNECTED) {
    mqtt.setServer(BROKER, 1883);
    if (mqtt.connect("esp32-station")) {
      sendValue("weather/temp", t, 1);
      sendValue("weather/hum", h, 0);
      sendValue("weather/press", p, 0);
      sendValue("weather/bat", vbat, 2);
      mqtt.loop(); delay(50);
    }
  }
  WiFi.disconnect(true);
  esp_sleep_enable_timer_wakeup(SLEEP_US);
  esp_deep_sleep_start();
}

void loop() {}
```

4. Измерь ток активной фазы и сна (INA219 или мультиметр) и время активной фазы.
5. Рассчитай срок по измеренным токам.

| Ток сна | ≈ 85 мкА | |
| Активная фаза, с | 4 | |
| Средний ток, мА | 0,75 | |
| Срок, суток | 108 | |

## Проверка

Ожидай: сообщения приходят раз в 10 минут; напряжение батареи 3,7–4,2 В в топике weather/bat; ток сна на DevKit будет ожидаемо большим (5–15 мА) — для проверки срока используй модуль без светодиода и стабилизатора платы. Срок по измерениям должен совпасть с расчётом в пределах 30 %.

## Если не работает

- **Сообщения не приходят.** Адрес брокера, порт 1883, сеть 2,4 ГГц, пароль.
- **Перезагрузки при подключении.** Просадка питания: проверь LDO и конденсаторы, заряд ячейки.
- **Ток сна велик.** Светодиод и регулятор DevKit; BME280 питается постоянно (допустимо); делитель батареи слишком низкоомный.
- **Неверное напряжение батареи.** Опорное и нелинейность ADC: калибруй по мультиметру.
- **Долгая активная фаза.** Используй статический IP и быстрое подключение, таймаут 8 с.
