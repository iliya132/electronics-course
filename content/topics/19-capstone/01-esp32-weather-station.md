## Цель

ТЗ: раз в 10 минут измерять температуру и влажность BME280, передавать JSON локальному MQTT-брокеру и спать. Цель по питанию — измеренный средний ток менее 1 мА на специализированной плате; обычная DevKit с LED и USB-UART может не выполнить её. Для одной 18650 используем защищённый держатель, зарядник TP4056 с подходящим током и малопотребляющий LDO. LDO перестаёт поддерживать 3,3 В, когда напряжения ячейки уже недостаточно; полезная ёмкость ниже паспортной.

## Что понадобится

- Классический ESP32-WROOM на плате с доступным измерением питания
- BME280 для 3,3 В; подтяжки I²C к 3,3 В
- Исправная защищённая 18650 в держателе, зарядник TP4056
- LDO 3,3 В с низким собственным током и достаточным импульсным током; конденсаторы по даташиту
- Локальный Wi-Fi и MQTT-брокер; библиотеки Adafruit BME280, Adafruit Unified Sensor, PubSubClient

Бюджет: сначала используй детали своего набора. Для планирования можно заложить 1500–5000 ₽ без измерительных приборов; это условный резерв, актуальные цены проверяй перед покупкой.

## Расчёт

Iср = (Iакт·tакт+Iсон·tсон)/T. Токи всей платы, включая стабилизатор и датчики, считают вместе.

## Сборка по шагам

1. Сначала проверь BME280 от USB: 3V3, GND, SDA21, SCL22; адрес 0x76 или 0x77.
2. Собери питание без ячейки: зарядник к держателю, защищённый выход через выключатель к LDO. Подбери ток заряда по ячейке, не по рекламе модуля.
3. Проверь LDO ограниченным источником во всём диапазоне напряжения ячейки и при импульсах нагрузки. Не соединяй его выход с другим 3V3-источником.
4. В скетче укажи SSID, пароль и IP локального брокера; проверь приём course/weather.
5. Отключи нагрузку при зарядке в этой схеме без power-path. Измерь цикл работы после перевода на батарейное питание.

```cpp
#include <WiFi.h>
#include <PubSubClient.h>
#include <esp_sleep.h>
#include <Wire.h>
#include <Adafruit_BME280.h>
Adafruit_BME280 bme;
bool beginSensor(){Wire.begin(21,22);return bme.begin(0x76)||bme.begin(0x77);}
const char* ssid="YOUR_WIFI";const char* password="YOUR_PASSWORD";
WiFiClient transport;PubSubClient mqtt(transport);
void setup(){
 Serial.begin(115200);bool ok=beginSensor();
 WiFi.begin(ssid,password);unsigned long start=millis();
 while(WiFi.status()!=WL_CONNECTED && millis()-start<12000)delay(100);
 if(ok && WiFi.status()==WL_CONNECTED){
  mqtt.setServer("192.168.1.10",1883);mqtt.setSocketTimeout(3);
  String id="weather-"+String((uint32_t)ESP.getEfuseMac(),HEX);
  if(mqtt.connect(id.c_str())){
   char json[96];snprintf(json,sizeof(json),"{"t":%.2f,"h":%.2f}",bme.readTemperature(),bme.readHumidity());
   bool sent=mqtt.publish("course/weather",json);Serial.println(sent?"sent":"failed");mqtt.loop();mqtt.disconnect();
  }
 }
 WiFi.disconnect(true);Serial.flush();
 esp_sleep_enable_timer_wakeup(600ULL*1000000ULL);esp_deep_sleep_start();
}
void loop(){}
```

## Проверка

При Iакт=80 мА в течение 3 с и Iсон=0,05 мА в течение 597 с средний ток 0,44975 мА. При полезной ёмкости 1800 мА·ч расчёт даёт около 4002 ч (167 суток); это оценка без саморазряда, старения и повторов Wi-Fi. Сверь лог сообщений и реальные токи за несколько циклов.

## Если не работает

- Постоянный LED или USB-мост портит бюджет сна.
- Нет Wi-Fi: проверь пароль, 2,4 ГГц и ограниченное время ожидания; устройство должно всё равно уснуть.
- LDO проседает при передаче: проверь dropout, ток, конденсаторы и провода.
- Брокер без авторизации допустим только в изолированной учебной сети; для реальной сети нужны учётные данные и TLS.
```callout
kind: mistake
text: >-
  Ток deep sleep из даташита равен току любой DevKit. Срок работы определяет средний ток всей платы,
  а не только ток сна кристалла.
```

## Безопасность

```callout
kind: safety
text: >-
  Не заряжай повреждённые Li-ion. Используй держатель, защиту и ограниченный ток. Не паяй к банке и
  не подключай одновременно USB и батарейный выход без схемы развязки.
```
