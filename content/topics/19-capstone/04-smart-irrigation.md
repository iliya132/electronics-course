## Цель

**Техническое задание.** Горшок поливается автоматически: ESP32 просыпается два раза в сутки, измеряет влажность почвы и при сухой почве включает насос на ограниченное время. Нельзя допускать затопления (отказ датчика) и сухого хода насоса (пустой бак). Питание от ячейки 18650. Проект объединяет датчик, силовой ключ, защиты и энергобюджет.

## Что понадобится

- ESP32 (модуль или DevKit), ёмкостный датчик влажности почвы (аналоговый, 3,3 В).
- Насос 5 В (около 0,3 А), MOSFET с логическим затвором (IRLZ44N или аналог), диод 1N5819 или 1N4007, резистор 100 Ом в затворе и 100 кОм подтяжка затвора к земле.
- Поплавковый выключатель, ячейка 18650 с TP4056 и защитой, LDO 3,3 В, повышающий модуль до 5 В (или насос на 3,7 В), PTC 1 А.
- Трубка, ёмкость для воды, лоток для горшка.

Цены условные, проверяй актуальные.

## Расчёт

- **Насос:** 5 В, 0,3 А = 1,5 Вт; MOSFET IRLZ44N при Uзи 3,3 В имеет сопротивление в милли­омах: потери I²R ≈ 0,09·0,05 ≈ 5 мВт — радиатор не нужен.
- **Объём полива:** производительность насоса 1 л/мин: за 9 с ≈ 150 мл на полив.
- **Энергия в сутки:** сон 85 мкА · 24 ч = 2,04 мА·ч; два измерения по 8 с при 90 мА = 0,4 мА·ч; два полива по 9 с при 300 мА = 1,5 мА·ч; итого ≈ **3,94 мА·ч** в сутки.
- **Срок:** 2600 мА·ч / 3,94 ≈ 660 суток по ёмкости; с запасом 0,75 — **≈ 495 суток**. На практике ограничит саморазряд и вода в баке, а не батарея.
- **Лимит:** если датчик «врёт» и показывает сухо всегда, ограничение 30 с на запуск и не более 2 запусков в сутки ограничивают максимум 2 · 0,3 л... ≈ 0,5 л за сутки.

## Сборка по шагам

1. Отключи питание. Цепь насоса: «+5 В» → насос → сток MOSFET; исток → земля. Диод параллельно насосу: катод к «+», анод к стоку.
2. Затвор: GPIO25 через 100 Ом; подтяжка 100 кОм к земле (насос не включится при сбросе).
3. Датчик влажности: питание 3,3 В, выход на GPIO34 (ADC1). Поплавок между GPIO27 (INPUT_PULLUP) и землёй.
4. Питание: 18650 → TP4056 → LDO 3,3 В; насосу 5 В от повышающего модуля с PTC 1 А.
5. Откалибруй датчик: значение в сухой почве/воздухе и в воде (получи два отсчёта), задай порог «сухо».
6. Скетч:

```cpp
#include <esp_sleep.h>
#include <esp_task_wdt.h>

const int PUMP = 25, SENSOR = 34, FLOAT_SW = 27;
const int DRY_RAW = 2600, WET_RAW = 1200;         // калибровка: воздух / вода
const int THRESHOLD_PCT = 35;                     // поливать при влажности ниже
const unsigned long PUMP_MS = 9000, MAX_PUMP_MS = 30000;
const uint64_t SLEEP_US = 12ULL * 3600ULL * 1000000ULL;   // 12 часов

int moisturePct() {
  long s = 0; for (int i = 0; i < 16; i++) { s += analogRead(SENSOR); delay(5); }
  int raw = s / 16;
  return constrain(map(raw, DRY_RAW, WET_RAW, 0, 100), 0, 100);
}

void setup() {
  pinMode(PUMP, OUTPUT); digitalWrite(PUMP, LOW);
  pinMode(FLOAT_SW, INPUT_PULLUP);
  esp_task_wdt_init(40, true);                    // сторожевой таймер 40 с
  esp_task_wdt_add(NULL);

  bool waterOk = digitalRead(FLOAT_SW) == LOW;    // поплавок замкнут при воде
  int m = moisturePct();
  if (m < THRESHOLD_PCT && waterOk) {
    unsigned long t0 = millis();
    digitalWrite(PUMP, HIGH);
    while (millis() - t0 < PUMP_MS && millis() - t0 < MAX_PUMP_MS) {
      esp_task_wdt_reset();
      if (digitalRead(FLOAT_SW) != LOW) break;    // вода кончилась — стоп
      delay(50);
    }
    digitalWrite(PUMP, LOW);
  }
  esp_sleep_enable_timer_wakeup(SLEEP_US);
  esp_deep_sleep_start();
}

void loop() {}
```

7. Проверь: насос выключается после 9 с; при поднятом поплавке не включается; при зависании программы WDT перезагружает ESP32 (насос выключен подтяжкой).

| Проверка | Ожидание | Результат |
|---|---|---|
| Сухая почва, вода есть | насос 9 с | |
| Влажная почва | насоса нет | |
| Поплавок поднят | насоса нет | |
| Ток сна | ≈ 85 мкА | |

## Проверка

Ожидай: сухой датчик (на воздухе) даёт сырое значение около 2600, в стакане с водой около 1200; насос включается на 9 с и выключается; после полива влажность растёт; ток сна не более нескольких сотен микроампер на очищенной плате. Проведи 3 суток тестового режима с коротким периодом и убедись, что нет переполива.

## Если не работает

- **Насос не включается.** MOSFET не логического уровня (не открыт 3,3 В), нет общей земли, перепутаны сток и исток.
- **Насос включается при подаче питания.** Нет подтяжки 100 кОм на затворе или затвор на «висящем» выводе.
- **ESP32 перезагружается при пуске насоса.** Бросок тока: конденсатор 470 мкФ на питании насоса и отдельный стабилизатор.
- **Показания датчика плавают.** Усредни 16 отсчётов, добавь 100 нФ и питай датчик только на время измерения.
- **Поливает при воде в баке.** Инверсия логики поплавка.
