## Цель

ТЗ: каждые 15 минут измерять влажность и при необходимости включать насос максимум на 3 секунды, не чаще раза в 6 часов. Насос управляется низкобоковым N-MOSFET с гарантированным RDS(on) при 3,3 В и обратным диодом. Поплавок блокирует работу без воды. Программное ограничение дополнено аппаратным таймером питания насоса максимум на 5 секунд; без него испытания проводятся только под наблюдением.

## Что понадобится

- ESP32, ёмкостный датчик влажности с выходом в диапазоне ADC 3,3 В
- Низковольтный насос, MOSFET с данными RDS(on) при 2,5–3,3 В
- Диод по току насоса, затворный резистор 100 Ом и 100 кОм к GND
- Поплавковый контакт, независимое ограничение питания насоса до 5 с
- Отдельный источник насоса и закрытый сухой отсек электроники

Бюджет: сначала используй детали своего набора. Для планирования можно заложить 1500–5000 ₽ без измерительных приборов; это условный резерв, актуальные цены проверяй перед покупкой.

## Сборка по шагам

1. Насос: плюс к защищённому питанию через независимый таймер, минус к drain; source к GND. Диод параллельно насосу: катод к плюсу, анод к drain.
2. GPIO25 через 100 Ом к gate, 100 кОм gate-source. Земли логики и насоса общие, силовая петля короткая.
3. Датчик к ADC34; проверь его максимальный выход. Поплавок GPIO27–GND замыкается только при наличии воды.
4. Измерь сухой и влажный грунт, выбери порог между ними и замени пример 2800. Коды около 0 и 4095 трактуются как отказ.
5. Сначала замени насос LED с резистором и проведи все отказные проверки. Затем измерь реальную подачу за 3 секунды в ёмкость.

```cpp
#include <esp_sleep.h>
const int PUMP=25,SOIL=34,FLOAT_SWITCH=27;
RTC_DATA_ATTR unsigned long cyclesSinceWater=24;
const unsigned long maxPumpMs=3000;
void setup(){
 pinMode(PUMP,OUTPUT);digitalWrite(PUMP,LOW);
 pinMode(FLOAT_SWITCH,INPUT_PULLUP);Serial.begin(115200);
 analogReadResolution(12);
 unsigned long sum=0;for(int i=0;i<16;i++){sum+=analogRead(SOIL);delay(10);}
 int raw=sum/16;cyclesSinceWater++;
 // Пример порога: заменить после своей калибровки; ADC 0/4095 — отказ.
 bool valid=raw>100 && raw<4000;
 // Поплавок замкнут на GND только при достаточном запасе воды.
 bool waterPresent=digitalRead(FLOAT_SWITCH)==LOW;
 if(valid && raw>2800 && waterPresent && cyclesSinceWater>=24){
  cyclesSinceWater=0;unsigned long start=millis();digitalWrite(PUMP,HIGH);
  while(millis()-start<maxPumpMs && digitalRead(FLOAT_SWITCH)==LOW)delay(10);
  digitalWrite(PUMP,LOW);
 }
 digitalWrite(PUMP,LOW);Serial.print("ADC=");Serial.println(raw);Serial.flush();
 esp_sleep_enable_timer_wakeup(900ULL*1000000ULL);esp_deep_sleep_start();
}
void loop(){}
```

## Проверка

При токе насоса 0,6 А и RDS(on)=0,05 Ом проводниковая потеря 0,018 Вт; переключение и выбросы считаются отдельно. Если за 3 с получено 60 мл, один полив даёт именно этот объём, а не условный процент. Проверь, что насос выключается при размыкании поплавка и что аппаратный таймер отключает питание при постоянном высоком GPIO.

## Если не работает

- При сбросе насос включается: проверь затворную подтяжку и полярность ключа.
- Мотор мешает ADC: разнеси токовые пути и измеряй при выключенном насосе.
- Частые поливы после полного обесточивания: RTC-память не сохраняет интервал после потери питания; нужен RTC/постоянное хранение для автономной эксплуатации.
- MOSFET пробит: прошивка его не выключит; нужен независимый разрыв силовой цепи.
```callout
kind: mistake
text: >-
  Один программный delay гарантирует выключение насоса при любой неисправности. Ограничение в
  прошивке не защищает от пробоя MOSFET или зависания контроллера.
```

## Безопасность

```callout
kind: safety
text: >-
  Не оставляй учебный прототип без наблюдения. Электроника и соединения должны оставаться сухими. Не
  используй сетевой насос. Предусмотри перелив, ограниченный запас воды и ручной выключатель.
```
