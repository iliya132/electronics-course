## Цель

Спроектируем простой шилд для Uno R3. Светодиоды, кнопка и I²C-разъём должны совпасть с механикой конкретной платы и не конфликтовать по выводам.

## Что понадобится

- KiCad, механические данные Uno R3
- Разъёмы, LED с 1 кОм, кнопка
- I²C-разъём с подписанными уровнями

Бюджет: сначала используй детали своего набора. Для планирования можно заложить 1500–5000 ₽ без измерительных приборов; это условный резерв, актуальные цены проверяй перед покупкой.

## Расчёт

Длина между крайними центрами = (N−1)·шаг. Габарит корпуса обычно больше.

## Сборка по шагам

1. Создай проект и схему: LED D8 через 1 кОм, кнопка D2–GND, I²C A4/A5, питание.
2. Назначь футпринты и проверь номера контактов. Запусти ERC.
3. Расставь разъёмы по проверенным координатам Uno; распечатай 1:1 для примерки.
4. Размести детали, проложи дорожки, залей землю, запусти DRC.
5. Экспортируй Gerber и сверловку, открой в просмотрщике.
## Проверка

Проверь совпадение всех центров разъёмов и отсутствие конфликта с USB/DC-корпусами. Для LED 5 В, Vf=2 В и 1 кОм ток ≈3 мА. ERC/DRC должны быть без необъяснённых ошибок; заказ платы необязателен.

```quiz
id: measurement
type: numeric
question: Разъём имеет 5 контактов с шагом 2,54 мм. Каково расстояние между центрами крайних контактов?
answer: 10.16
unit: мм
tolerance_percent: 1
hint: Длина между крайними центрами = (N−1)·шаг. Габарит корпуса обычно больше.
explanation: (5−1)×2,54 = 10,16 мм.
```

## Если не работает

- Выбран механический шаблон другого Uno.
- Перевёрнуты номера площадок.
- I²C-подтяжки конфликтуют с уровнями датчика.
```callout
kind: mistake
text: >-
  Все разъёмы Uno лежат на единой регулярной сетке. Механическое соответствие шилда проверяют
  независимо от электрической схемы.
```

## Безопасность

```callout
kind: safety
text: >-
  Собирай без питания. Работай только от защищённого низковольтного источника с ограничением тока.
  Не подключай сетевое напряжение.
```
