## Цель

Соберём веб-датчик: ESP32 читает BME280 и отдаёт страницу, которую можно открыть с любого устройства в той же сети. Данные обновляются каждые 2 секунды без перезагрузки страницы. Проект закрепляет Wi-Fi, I²C и работу с JSON.

## Что понадобится

- ESP32 DevKit.
- Модуль BME280 (I²C, 3,3 В, адрес 0x76 или 0x77).
- Провода, макетная плата, USB-кабель с данными.
- Библиотеки Adafruit BME280 и Adafruit Unified Sensor (менеджер библиотек).

Цены условные, проверяй актуальные.

## Расчёт

- **Адрес BME280:** 0x76 (SDO на землю) или 0x77 (SDO к 3,3 В).
- **Подтяжки I²C:** обычно уже на модуле (4,7 кОм). Если нет — поставь 4,7 кОм к 3,3 В на SDA и SCL.
- **Размер JSON:** `{"t":23.4,"h":48,"p":1012}` ≈ 27 байт; ответ с HTTP-заголовком ≈ 200 байт.
- **Трафик:** запрос раз в 2 с: 1800 запросов в час · 200 байт = **360 КБ/час**.
- **Потребление:** ESP32 в Wi-Fi 80–120 мА (пики 300 мА); BME280 ≈ 0,004 мА. Для питания от USB достаточно.
- **Самонагрев:** BME280 при редких измерениях нагревается менее чем на 0,1 °C.

## Сборка по шагам

1. Отключи питание. Подключи BME280: VIN → 3V3, GND → GND, SDA → GPIO21, SCL → GPIO22.
2. Установи библиотеки и пакет ESP32 в Arduino IDE; выбери плату «ESP32 Dev Module».
3. Загрузи скетч (подставь свою сеть):

```cpp
#include <WiFi.h>
#include <WebServer.h>
#include <Wire.h>
#include <Adafruit_BME280.h>

const char* SSID = "имя_сети";
const char* PASS = "пароль_сети";

Adafruit_BME280 bme;
WebServer server(80);

const char PAGE[] PROGMEM = R"HTML(
<!doctype html><html><head><meta charset="utf-8"><meta name="viewport" content="width=device-width">
<title>Метеодатчик</title></head><body style="font-family:sans-serif">
<h1>Метеодатчик</h1>
<p>Температура: <b id="t">–</b> °C</p>
<p>Влажность: <b id="h">–</b> %</p>
<p>Давление: <b id="p">–</b> гПа</p>
<script>
async function upd(){
  const r = await fetch('/data'); const d = await r.json();
  document.getElementById('t').textContent = d.t;
  document.getElementById('h').textContent = d.h;
  document.getElementById('p').textContent = d.p;
}
upd(); setInterval(upd, 2000);
</script></body></html>
)HTML";

void handleRoot() { server.send(200, "text/html; charset=utf-8", PAGE); }

void handleData() {
  String j = "{\"t\":" + String(bme.readTemperature(), 1) +
             ",\"h\":" + String(bme.readHumidity(), 0) +
             ",\"p\":" + String(bme.readPressure() / 100.0F, 0) + "}";
  server.send(200, "application/json", j);
}

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);
  if (!bme.begin(0x76)) { Serial.println("BME280 не найден"); while (true) {} }
  WiFi.begin(SSID, PASS);
  while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); }
  Serial.println(WiFi.localIP());
  server.on("/", handleRoot);
  server.on("/data", handleData);
  server.begin();
}

void loop() { server.handleClient(); }
```

4. Открой монитор порта (115200) и найди адрес, например 192.168.1.50.
5. Введи адрес в браузере телефона или компьютера (в той же сети) и проверь, что значения обновляются.
6. Подуй на датчик или поднеси тёплую руку: температура и влажность должны меняться за 5–10 с.
7. Запиши показания и сравни с бытовым термометром.

| Условие | Температура, °C | Влажность, % | Давление, гПа |
|---|---|---|---|
| Комната | | | |
| После дыхания (влажность) | | | |

## Проверка

Ожидай: страница открывается по IP; значения обновляются раз в 2 с; температура близка к термометру (±1 °C); влажность 30–60 % в комнате, при дыхании растёт на 10–20 %; давление 980–1040 гПа. Если BME280 не найден, проверь адрес (0x77) и подключение.

## Если не работает

- **Адрес не выводится.** Неверный пароль или сеть 5 ГГц (ESP32 работает только на 2,4 ГГц).
- **Страница не открывается.** Телефон в другой сети или адрес записан неправильно.
- **Значения «NaN».** Датчик не отвечает: проверь питание 3,3 В и адрес.
- **Температура завышена.** Датчик рядом с ESP32 или платой, которые нагреваются; вынеси датчик на провод.
- **Страница обновляется редко.** Закрыт JavaScript или ответ долго формируется; проверь /data в браузере.

