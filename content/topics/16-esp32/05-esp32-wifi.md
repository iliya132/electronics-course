## Подключение и режимы

В режиме **STA** (station) ESP32 подключается к роутеру: `WiFi.mode(WIFI_STA); WiFi.begin(ssid, pass);` и ждёт `WiFi.status() == WL_CONNECTED`. Адрес выдаёт роутер (DHCP). В режиме **AP** (access point) ESP32 сама создаёт сеть: `WiFi.softAP("ESP32-config", "12345678");` — адрес по умолчанию 192.168.4.1, удобно для первой настройки пароля сети.

## Веб-сервер и JSON

Библиотека `WebServer` позволяет привязать функции к адресам: `/` отдаёт HTML-страницу, `/data` — JSON с показаниями. Страница может обновляться сама (`<meta http-equiv='refresh'>` или JavaScript `fetch`). JSON — простой текст `{"temp":23.4}`, его удобно читать скриптами и приложениями.

```cpp
#include <WiFi.h>
#include <WebServer.h>

const char* SSID = "имя_сети";           // не публикуй реальные данные!
const char* PASS = "пароль_сети";
WebServer server(80);

float readTemp() { return 23.4; }        // замени чтением датчика

void handleRoot() {
  String page = "<html><head><meta charset='utf-8'><meta http-equiv='refresh' content='5'></head>"
                "<body><h1>Температура</h1><p>" + String(readTemp(), 1) + " &deg;C</p></body></html>";
  server.send(200, "text/html; charset=utf-8", page);
}

void handleData() {
  String json = "{\"temp\":" + String(readTemp(), 1) + ",\"rssi\":" + String(WiFi.RSSI()) + "}";
  server.send(200, "application/json", json);
}

void setup() {
  Serial.begin(115200);
  WiFi.mode(WIFI_STA);
  WiFi.begin(SSID, PASS);
  while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); }
  Serial.println(WiFi.localIP());        // адрес для браузера
  server.on("/", handleRoot);
  server.on("/data", handleData);
  server.begin();
}

void loop() {
  server.handleClient();
}
```

## Качество связи и безопасность

**RSSI** — мощность сигнала: −30…−50 дБм отличный, −50…−67 хороший, −67…−75 средний, ниже −85 почти нет связи. `WiFi.RSSI()` возвращает значение. Для устойчивой работы нужна WPA2 и сложный пароль; пароль не хранят в публичном репозитории; при публикации страницы за пределами домашней сети ставят пароль и HTTPS. ESP32 поддерживает только 2,4 ГГц.

```figure
file: esp32-wifi/rssi.svg
alt: "Таблица уровня сигнала Wi-Fi. RSSI от минус 30 до минус 50 дБм — отличное, рядом с роутером. От минус 50 до минус 67 — хорошее, стабильное соединение. От минус 67 до минус 75 — среднее, возможны потери. От минус 75 до минус 85 — слабое, нестабильно. Ниже минус 85 — почти нет связи."
caption: "Оценка RSSI: чем ближе к нулю, тем сильнее сигнал."
```
