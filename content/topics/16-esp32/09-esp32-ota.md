Когда ESP32 уже на потолке или в оранжерее, прошивать её кабелем неудобно. Обновление «по воздуху» (OTA, over-the-air) позволяет загрузить новую версию по Wi-Fi. Это удобно, но требует аккуратной разметки Flash и мер безопасности.

## Разделы Flash

Flash делится на разделы: загрузчик и таблица разделов, **nvs** (настройки), **otadata** (какой слот активен), два слота приложения **ota_0** и **ota_1**. При обновлении программа записывается в неактивный слот, проверяется (CRC/подпись), затем otadata переключает загрузку на него; при сбое можно откатиться.

## Порядок обновления

Обновление идёт по шагам: получить образ `.bin`, записать во второй слот, проверить CRC или подпись, переключить слот, перезагрузиться. Если новая программа при старте не подтвердила работоспособность, срабатывает **откат** (rollback). Самый простой вариант — `ArduinoOTA`: плата появляется в списке портов Arduino IDE по сети.

```figure
file: esp32-ota/flow.svg
alt: "Цепочка из пяти шагов: получить образ bin, записать во второй слот, проверить CRC или подпись, переключить слот, перезагрузка и откат при сбое."
caption: "Порядок обновления по воздуху."
```

```cpp
#include <WiFi.h>
#include <ArduinoOTA.h>

void setup() {
  WiFi.begin("имя_сети", "пароль_сети");
  while (WiFi.status() != WL_CONNECTED) delay(500);
  ArduinoOTA.setHostname("esp32-sensor");
  ArduinoOTA.setPassword("пароль_ota");     // обязательно задай пароль
  ArduinoOTA.begin();
}

void loop() {
  ArduinoOTA.handle();                       // слушаем запросы на обновление
  // основная работа
}
```


## Безопасность

OTA открывает «дверь» в устройство. Без пароля любой в сети может загрузить свою прошивку. Минимум: пароль, доступ только из доверенной сети, шифрование (HTTPS/TLS) и **подпись** образа (secure boot). В домашнем проекте достаточно пароля и закрытой сети; в продукте — подпись и шифрование.

```callout

```
