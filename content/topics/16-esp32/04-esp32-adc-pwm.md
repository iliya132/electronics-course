## АЦП: диапазон и точность

АЦП ESP32 12-битный: 4096 кодов. Вход ослабляют, чтобы измерять больше 1 В: **0 дБ** — до 0,95 В, **11 дБ** — до 2,45 В (рабочий диапазон 0,15–2,45 В). Выше диапазона и около нуля АЦП нелинейно. **ADC1** (GPIO32–39) работает всегда, **ADC2** — только без Wi-Fi. Функция `analogReadMilliVolts(pin)` использует заводскую калибровку и возвращает напряжение в мВ.

```figure

caption: "Ослабление и рабочий диапазон АЦП ESP32."
```

```cpp
const int PIN = 34;                      // ADC1 — можно использовать при Wi-Fi

void setup() {
  Serial.begin(115200);
  analogReadResolution(12);              // 12 бит
  analogSetPinAttenuation(PIN, ADC_11db);// диапазон до ≈ 2,45 В
}

void loop() {
  long sum = 0;
  for (int i = 0; i < 32; i++) sum += analogReadMilliVolts(PIN);   // усреднение
  Serial.print(sum / 32.0, 0);
  Serial.println(" мВ");
  delay(500);
}
```

## Погрешности и калибровка

Нелинейность и разброс чипов дают ошибку до нескольких процентов. Борются усреднением (16–64 выборок), калибровкой по двум точкам (холодное/горячее значение) и, при необходимости, внешним АЦП (ADS1115, 16 бит, I²C). Делитель напряжения подбирают так, чтобы рабочий диапазон попал в середину линейной области (1–2 В). Конденсатор 100 нФ у входа снижает шум.

```example

  - "Берём 120 кОм (сверху) и 100 кОм (снизу): 100/220 = 0,4545; 5 В → 2,27 В — укладывается."
  - "Сопротивление источника делителя 55 кОм слишком велико: ставим конденсатор 100 нФ или буфер."

```

## ШИМ через LEDC

LEDC — аппаратный ШИМ-контроллер с 16 каналами. Нужно задать частоту и разрядность: для 8 бит предел частоты 312 кГц, для 12 бит — 19,5 кГц (f·2^бит ≤ 80 МГц). Типичные значения: 5 кГц и 8–12 бит для светодиодов; 25 кГц для вентиляторов. Запись `ledcWrite(pin, значение)` от 0 до 2^бит − 1.

```cpp
const int LED = 18;

void setup() {
  ledcAttach(LED, 5000, 12);            // пин, частота 5 кГц, 12 бит (ядро 3.x)
  // для ядра 2.x: ledcSetup(0, 5000, 12); ledcAttachPin(LED, 0);
}

void loop() {
  for (int d = 0; d <= 4095; d += 64) { ledcWrite(LED, d); delay(10); }   // плавное включение
  for (int d = 4095; d >= 0; d -= 64) { ledcWrite(LED, d); delay(10); }   // плавное выключение
}
```
