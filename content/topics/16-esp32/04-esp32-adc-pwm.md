## Как это устроено

Диапазон АЦП зависит от ослабления и калибровки; в классическом ESP32 ADC2 конфликтует с Wi-Fi. LEDC формирует ШИМ, причём высокая частота ограничивает доступную разрядность. В Arduino-ESP32 3.x ledcAttach и ledcWrite работают с выводами.

## Модель и единицы

LSB = Uref/2ⁿ; n — число битов. Код ограничен диапазоном 0…2ⁿ−1.

Для датчика во время Wi-Fi выбирай совместимый ADC1 и проверяй диапазон. Используй калиброванное измерение напряжения, если API его поддерживает.

## Проверяем на практике

Для датчика во время Wi-Fi выбирай совместимый ADC1 и проверяй диапазон. Используй калиброванное измерение напряжения, если API его поддерживает.

До подключения найди общий провод и проверь режим прибора. Изменяй один параметр за раз, записывай расчёт и измерение. Несовпадение сначала проверь по единицам и условиям модели.

```cpp
void setup(){ledcAttach(25,5000,8);ledcWrite(25,128);}
void loop(){}
```
