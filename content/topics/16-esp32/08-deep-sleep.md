Батарея на 2600 мА·ч при токе ESP32 в Wi-Fi 100 мА разрядится за сутки. Но если датчик большую часть времени спит и просыпается лишь на секунды, тот же аккумулятор проработает месяцы. Всё зависит от времени сна и от того, что ещё стоит на плате.


## Режимы сна

**Light sleep** останавливает ядро, но сохраняет RAM: пробуждение за миллисекунды, ток ≈ 0,8 мА. **Deep sleep** отключает всё, кроме RTC-контроллера, ток ≈ 10 мкА (сам чип), а после пробуждения программа начинается заново (setup()). Источники пробуждения: таймер (`esp_sleep_enable_timer_wakeup(мкс)`), внешний вывод (EXT0/EXT1, GPIO RTC), касание. Данные сохраняют в RTC-памяти (`RTC_DATA_ATTR`) или NVS.

```cpp
#include <esp_sleep.h>

RTC_DATA_ATTR int bootCount = 0;            // живёт между пробуждениями

void setup() {
  Serial.begin(115200);
  bootCount++;
  Serial.printf("Пробуждение №%d\n", bootCount);

  // 1) быстро выполнить измерение и отправку (3 с)
  // measureAndSend();

  // 2) заснуть на 10 минут
  esp_sleep_enable_timer_wakeup(600ULL * 1000000ULL);     // в микросекундах
  esp_deep_sleep_start();
}

void loop() {}                              // сюда не дойдёт
```

## Расчёт срока работы

Средний ток: **I_ср = (I_акт·t_акт + I_сон·t_сон) / T**. Срок = ёмкость / I_ср с поправкой на неполный разряд и КПД (0,7–0,8).

```example
title: Срок работы от 18650
steps:
  - "Цикл T = 600 с: активность 3 с при 80 мА, сон 597 с при 10 мкА."
  - "I_ср = (80·3 + 0,01·597)/600 = 245,97/600 ≈ 0,41 мА."
  - "Идеальный срок 2600/0,41 ≈ 6341 ч ≈ 264 суток."
  - "С учётом саморазряда и КПД 0,7: ≈ 185 суток — около полугода."
result: около 264 суток идеально, ≈ 185 с запасом
```

## Что ещё потребляет

В deep sleep самого чипа 10 мкА, но на DevKit остаются стабилизатор AMS1117 (≈ 5 мА собственного тока), светодиод питания (≈ 2 мА) и USB-UART (мА): общий ток 5–15 мА! Для батарейных проектов берут модуль без лишнего или плату с малопотребляющим LDO (ток покоя 1–5 мкА), убирают светодиод и питают датчики через GPIO-ключ.

```callout
kind: mistake
text: "Измеряют ток DevKit в deep sleep, видят 8 мА и делают вывод «sleep не работает». На самом деле сам чип спит, а ток потребляют стабилизатор, светодиод и USB-UART. Отключай их или измеряй ток на модуле с отдельным LDO."
```

```callout
kind: board
text: "На платах для батарейных датчиков стоят: LDO с малым током покоя (HT7333, MCP1700), кнопка пробуждения на RTC-выводе, пары MOSFET для отключения датчиков, отсутствие светодиода питания. Фитиль платы — аккуратная разводка земли и отсутствие утечек."
```
