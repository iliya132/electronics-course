## Цель

Измерим, сколько энергии тратит периодически просыпающийся датчик. Сравним расчёт по фазам с измерением всей платы.

## Что понадобится

- Классический ESP32 DevKit, USB-кабель
- BME280 с питанием и подтяжками 3,3 В
- Библиотека Adafruit BME280 с зависимостями
- Измеритель тока с подходящими диапазонами

Бюджет: сначала используй детали своего набора. Для планирования можно заложить 1500–5000 ₽ без измерительных приборов; это условный резерв, актуальные цены проверяй перед покупкой.

## Расчёт

Iср = (Iакт·tакт+Iсон·tсон)/T. Токи всей платы, включая стабилизатор и датчики, считают вместе.

## Сборка по шагам

1. Подключи BME280 и проверь обычное измерение.
2. Загрузи скетч и проверь счётчик пробуждений в Serial.
3. Отключи лишние потребители только согласно схеме платы; измерь сон и активную фазу.
4. Посчитай средний ток всей платы и сравни с интегральным измерением.

[Скачать скетч .ino](/examples/sleepy-sensor/sleepy-sensor.ino)

```cpp
#include <esp_sleep.h>
#include <Wire.h>
#include <Adafruit_BME280.h>
Adafruit_BME280 bme;
bool beginSensor(){Wire.begin(21,22);return bme.begin(0x76)||bme.begin(0x77);}
RTC_DATA_ATTR uint32_t boots=0;
void setup(){
 Serial.begin(115200);boots++;
 if(beginSensor())Serial.printf("Boot %lu: %.2f C\n",(unsigned long)boots,bme.readTemperature());
 else Serial.println("Sensor error");
 Serial.flush();esp_sleep_enable_timer_wakeup(600ULL*1000000ULL);esp_deep_sleep_start();
}
void loop(){}
```

## Проверка

Таймер сна задан на 600 с; полный период включает ещё активную фазу. При расчёте по фиксированному циклу нужно явно выбрать, входят ли эти секунды в период. Для 3 с активности в цикле 600 с модель даёт 0,40995 мА.

## Если не работает

- Неверное питание или адрес BME280.
- Выбран другой ESP32-вариант или неподходящая версия библиотеки.
- Связь отсутствует или источник питания проседает.
```callout
kind: mistake
text: >-
  Светодиод питания не влияет на ток сна. Ток DevKit во сне может быть значительно выше тока самого
  ESP32.
```
