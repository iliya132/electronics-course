BLE (Bluetooth Low Energy) — это радио для небольших порций данных: температура, пульс, брелок. Телефон поддерживает его по умолчанию, а ESP32 потребляет в нём в десятки раз меньше, чем в Wi-Fi. Для батарейных датчиков это идеальный выбор.

## GATT

В BLE данные организованы иерархией **GATT**: устройство (сервер) содержит **сервисы** (набор связанных функций, например Environmental Sensing с UUID 0x181A), каждый сервис — **характеристики** (конкретные значения: Temperature 0x2A6E, Humidity 0x2A6F) с правами: чтение, запись, **уведомление** (notify — сервер сам присылает новое значение). Телефон (клиент) подключается и читает или подписывается.

## Рассылка и соединение

В режиме **advertising** устройство каждые 100 мс – 1 с рассылает пакеты с именем и UUID сервиса; телефон видит устройство в списке и может подключиться. В **соединении** стороны общаются в заданные интервалы (7,5 мс – 4 с). Потребление ESP32 в BLE — от сотен микроампер до нескольких миллиампер средних в зависимости от интервалов, намного меньше Wi-Fi.

```figure
file: ble/modes.svg
alt: "Таблица режимов BLE. Advertising: интервал 100 мс–1 с, ток 0,1–5 мА в импульсах, для маячков и поиска. Connected: интервал 7,5 мс–4 с, ток 0,1–10 мА, для чтения и уведомлений. Wi-Fi для сравнения: постоянно, 80–120 мА."
caption: "Рассылка и соединение BLE против Wi-Fi."
```

```cpp
#include <BLEDevice.h>
#include <BLEServer.h>
#include <BLE2902.h>

#define SERVICE_UUID "181A"          // Environmental Sensing
#define CHAR_UUID    "2A6E"          // Temperature

BLECharacteristic* tempChar;

void setup() {
  BLEDevice::init("ESP32-Temp");
  BLEServer* server = BLEDevice::createServer();
  BLEService* service = server->createService(SERVICE_UUID);
  tempChar = service->createCharacteristic(CHAR_UUID,
      BLECharacteristic::PROPERTY_READ | BLECharacteristic::PROPERTY_NOTIFY);
  tempChar->addDescriptor(new BLE2902());     // разрешает уведомления
  service->start();
  BLEDevice::getAdvertising()->addServiceUUID(SERVICE_UUID);
  BLEDevice::startAdvertising();
}

void loop() {
  int16_t t = 2345;                           // 23,45 °C в сотых долях градуса
  tempChar->setValue((uint8_t*)&t, 2);
  tempChar->notify();                         // отправить уведомление
  delay(2000);
}
```

```example
title: Как разобрать значение температуры
steps:
  - "В характеристике 0x2A6E лежат два байта: 0x29 0x09 (little-endian)."
  - "Собираем число: 0x0929 = 2345."
  - "Значение в сотых долях градуса: 2345 / 100 = 23,45 °C."
  - "Телефонное приложение nRF Connect показывает «0x2909», и результат нужно перевести вручную, если оно не знает формата."
result: 23,45 °C
```

## BLE или Wi-Fi

BLE выбирают для близкого общения с телефоном и экономии энергии, Wi-Fi — для доступа в интернет и больших данных. Скорость BLE — десятки килобит в секунду, дальность 10–30 м. Для безопасности нужно сопряжение (pairing) и шифрование; открытые характеристики может прочитать любой в радиусе.

```callout
kind: mistake
text: "Передают через BLE большие файлы или поток данных: пакеты BLE малы (20–244 байта), скорость десятки кбит/с. Для файлов и видео нужен Wi-Fi; BLE подходит для небольших значений и команд."
```

```callout

```
