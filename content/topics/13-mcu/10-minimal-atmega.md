## Цель

Запустим ATmega328P вне готовой Arduino-платы. Минимальная система включает питание, развязку, сброс, тактирование и способ загрузки программы.

## Что понадобится

- ATmega328P-PU с известными fuse/bootloader либо ISP-программатор
- Источник 5 В, два конденсатора развязки 100 нФ
- Кварц 16 МГц и нагрузочные C по CL, RESET 10 кОм
- LED с 1 кОм, USB-UART нужного уровня при наличии bootloader

Бюджет: сначала используй детали своего набора. Для планирования можно заложить 1000–2500 ₽ без измерительных приборов; это условный резерв, актуальные цены проверяй перед покупкой.

## Расчёт

## Сборка по шагам

1. По даташиту DIP-28 подключи VCC 7 и AVCC 20 к 5 В, GND 8 и 22 к земле; добавь развязку.
2. RESET 1 подтяни через 10 кОм к 5 В. Кварц подключи между XTAL1 9 и XTAL2 10 с рассчитанными C к GND.
3. Для пустого чипа используй ISP: MOSI 17, MISO 18, SCK 19, RESET, VCC и GND; установи корректные fuse.
4. Для чипа с Uno bootloader UART RX 2/TX 3 подключи крест-накрест, общий GND; сброс сформируй по схеме bootloader.
5. LED с резистором подключи к PB5 19 и GND. Загрузи Blink для выбранного ядра.

```cpp
void setup(){ pinMode(13, OUTPUT); }
void loop(){ digitalWrite(13,HIGH); delay(500); digitalWrite(13,LOW); delay(500); }
```

## Проверка

При 16 МГц один такт равен 62,5 нс. Для кварца с CL=12 пФ и паразитной 2 пФ симметричные C≈20 пФ; 22 пФ допустимы только при соответствующих условиях. Проверь питание около номинала и мигание с заданным периодом.

## Если не работает

- Нет bootloader, но используется UART-загрузка.
- Fuse выбраны под отсутствующий источник тактирования.
- Пропущены AVCC или один из GND.
```callout
kind: mistake
text: >-
  Любой пустой ATmega сразу программируется по UART. Наличие USB-UART не заменяет bootloader или ISP
  для пустого чипа.
```
