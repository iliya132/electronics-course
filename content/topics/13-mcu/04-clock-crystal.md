## Внутренний RC и кварц

В МК встроен **RC-генератор** (у ATmega328P 8 МГц): не требует деталей, но точность ±2…10 % и зависит от температуры и питания. **Кварцевый резонатор** — это пластина кварца, колеблющаяся с очень стабильной частотой; МК запускает её встроенным усилителем между выводами XTAL1 и XTAL2. Точность обычного кварца ±20–50 ppm (миллионных долей).

## Нагрузочные конденсаторы

Кварц рассчитан на определённую **ёмкость нагрузки CL** (указана в даташите: 12, 18, 20 пФ). Чтобы он колебался на номинальной частоте, внешние конденсаторы C1 и C2 вместе с паразитной ёмкостью дорожек Cпар должны дать именно эту ёмкость: **CL = C1·C2/(C1 + C2) + Cпар**. Для C1 = C2 = C получаем **C = 2·(CL − Cпар)**.

```figure
file: clock-crystal/crystal.svg
alt: "Схема. Микроконтроллер соединён выводами XTAL1 и XTAL2 с кварцем Y1 16 МГц с CL 12 пФ. От каждого вывода кварца конденсатор C1 и C2 по 18 пФ идёт на землю. Формула: CL равно C1 на C2 делить на C1 плюс C2 плюс Cпар, то есть 18 умножить на 18 делить на 36 плюс 3, получается 12 пФ."
caption: "Кварц с нагрузочными конденсаторами: CL определяет частоту."
```

```example
title: Нагрузочные конденсаторы для кварца CL = 12 пФ
steps:
  - "Принимаем паразитную ёмкость Cпар = 3 пФ (дорожки и выводы)."
  - "C = 2·(CL − Cпар) = 2·(12 − 3) = 18 пФ."
  - "Проверка: 18·18 / 36 + 3 = 9 + 3 = 12 пФ ✓."
  - "Ближайшее значение из E12 — 18 пФ; для CL = 18 пФ нужно было бы 30 пФ (берут 27 или 33)."
result: C1 = C2 = 18 пФ
```

## Когда что выбирать

Внутренний RC хватает для мигания светодиодом и простой логики. Кварц нужен для UART (допустима ошибка ≤ 2 %), USB (часы с точностью 0,25 %), радиоканалов и часов. Arduino Uno использует кварц 16 МГц и два конденсатора по 22 пФ. Для ультраточных часов берут часовой кварц 32,768 кГц с внешним RTC (DS3231) или TCXO.

```callout
kind: mistake
text: "Ставят кварц и конденсаторы «как в первой попавшейся схеме», не проверяя CL. Кварц с CL = 12 пФ, поставленный с конденсаторами 22 пФ, работает на частоте на 50–100 ppm ниже или вообще не запускается. Рассчитай C по формуле, учитывая Cпар, и подбери ближайший номинал."
```

```callout
kind: board
text: "Кварц на плате — металлический «корпус-таблетка» HC-49 или маленький керамический SMD с надписью 16.000 или 8.000. Рядом два конденсатора на землю по 12–27 пФ. Дорожки к кварцу короткие, вокруг — земляная заливка."
```

## Опыт на стенде

```bench
title: "Проверка частоты тактирования по выходному сигналу"

  - "Сравни с идеальной: отклонение в ppm = (f − 1000) / 1000 · 10⁶."
  - "Если есть плата с кварцем и плата с керамическим резонатором, сравни обе."

  - "Кварц даёт отклонение десятки ppm, керамический резонатор до 0,5 % (5000 ppm)."
  - "Измерение осциллографом тоже имеет погрешность, поэтому различия меньше 0,01 % считай неразличимыми."
  - "Для UART на 115200 бод отклонение тактовой частоты не должно превышать нескольких процентов."
```
