## Цель

Подключим OLED и убедимся в его адресе до вывода изображения. Сканер проверит ответ на адрес, после чего библиотека отправит команды контроллеру.

## Что понадобится

- Uno R3 и совместимый OLED SSD1306 128×64
- Библиотеки Adafruit GFX и SSD1306
- При наличии логический анализатор допустимых уровней

Бюджет: сначала используй детали своего набора. Для планирования можно заложить 1500–5000 ₽ без измерительных приборов; это условный резерв, актуальные цены проверяй перед покупкой.

## Расчёт

Rmax = tr,max/(0,8473C). Rmin = (VDD−VOLmax)/IOL; допустимый диапазон должен быть непустым.

## Сборка по шагам

1. Подключи SDA к A4 и SCL к A5, питание согласно модулю, общий GND.
2. Выполни сканер из урока I²C и запиши адрес.
3. Установи адрес в коде, затем загрузи программу вывода текста.
4. При наличии анализатора проверь START, адрес, ACK и передаваемые байты.

[Скачать скетч .ino](/examples/oled-i2c/oled-i2c.ino)

```cpp
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
Adafruit_SSD1306 display(128,64,&Wire,-1);
void setup(){
 if(!display.begin(SSD1306_SWITCHCAPVCC,0x3C))while(true){}
 display.clearDisplay();display.setTextColor(SSD1306_WHITE);display.setTextSize(1);display.setCursor(0,0);
 display.println("Electronics course");display.display();
}
void loop(){}
```

## Проверка

При адресе 0x3C сканер должен показать 3C, а дисплей — строку Electronics course. На осциллограмме SDA должна быть стабильна во время высокого SCL, кроме START/STOP.

```quiz
explanation: 1000×10⁻⁹/(0,8473×200×10⁻¹²)/1000 = 5,9011 кОм.
```

## Если не работает

- Адрес 0x3D вместо 0x3C.
- Контроллер экрана отличается от SSD1306.
- Неверные уровни питания или подтяжек.
```callout
kind: mistake
text: >-
  Любой найденный адрес означает исправную картинку. Ответ на адрес подтверждает присутствие
  устройства, но не правильную настройку дисплея.
```
