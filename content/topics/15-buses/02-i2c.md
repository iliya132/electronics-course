I²C придумали, чтобы подключить десятки микросхем всего двумя проводами. Датчики, дисплеи, память, часы — большинство «модулей для Arduino» говорят по I²C. Разберёмся, как это устроено.

## Устройство шины

Шина состоит из двух линий с открытым стоком: **SDA** (данные) и **SCL** (такт). Подтяжки к питанию создают высокий уровень. Ведущий (МК) формирует такт и выбирает устройство адресом. Адрес 7-битный; к нему добавляется бит R/W (0 — запись, 1 — чтение). Каждый байт подтверждается девятым битом **ACK** (ведомый тянет SDA вниз).

## Скорость и подтяжка

Режимы: **100 кГц** (стандартный), **400 кГц** (быстрый), 1 МГц (быстрый плюс). Время передачи одного байта при 100 кГц — 9 бит / 100 кГц = 90 мкс, при 400 кГц — 22,5 мкс. Подтяжка Rп ограничена снизу током насыщения (Rmin = (Vcc − 0,4)/3 мА ≈ 970 Ом при 3,3 В) и сверху временем нарастания (Rmax = t_r/(0,8473·C)). При ёмкости шины 100 пФ для 100 кГц Rmax ≈ 11,8 кОм, для 400 кГц ≈ 3,5 кОм.

## Сканер и проблемы

Сканер перебирает адреса и выводит те, на которые пришёл ACK.

```cpp
#include <Wire.h>

void setup() {
  Serial.begin(9600);
  Wire.begin();
  for (byte addr = 1; addr < 127; addr++) {
    Wire.beginTransmission(addr);
    if (Wire.endTransmission() == 0) {      // 0 = устройство ответило
      Serial.print("Найдено: 0x");
      Serial.println(addr, HEX);
    }
  }
}

void loop() {}
```

Типичные проблемы: нет подтяжек (или две пары на длинных линиях — слишком малое сопротивление), совпадающие адреса, перепутанные SDA и SCL, шина «зависла» (устройство держит SDA в нуле), длинные провода (ёмкость выше 400 пФ), смешение 3,3 и 5 В.

```callout
kind: mistake
text: "Подключают к одной шине I²C несколько готовых модулей, на каждом из которых стоят подтяжки 4,7 кОм: параллельное соединение даёт 1 кОм и меньше, а выход не может вытянуть линию в ноль при токе 3 мА. Лишние подтяжки выпаивают или отключают."
```

```callout
kind: board
text: "Около разъёма I²C на плате видны два резистора 4,7 кОм к питанию и, возможно, пары конденсаторов 10–47 пФ к земле. Рядом перемычки A0–A2, меняющие младшие биты адреса микросхемы (EEPROM, PCF8574, ADS1115)."
```
