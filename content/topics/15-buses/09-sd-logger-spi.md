## Цель

Сохраним температуру и время работы в CSV на SD. Карта требует корректного питания, уровней SPI и закрытия файла для сброса буферов. Отключение во время записи может повредить файл.

## Что понадобится

- Uno R3
- SD-модуль с преобразованием 5 В логики и картой
- NTC 10 кОм β3950 и резистор 10 кОм
- Встроенная SD-библиотека

Бюджет: сначала используй детали своего набора. Для планирования можно заложить 1500–5000 ₽ без измерительных приборов; это условный резерв, актуальные цены проверяй перед покупкой.

## Сборка по шагам

1. Собери NTC-делитель на A0: 5 В → 10 кОм → A0 → NTC → GND.
2. Подключи SD: CS=D10, MOSI=D11, MISO=D12, SCK=D13; питание по модулю.
3. Загрузи программу; проверь сообщения Serial.
4. Останови питание после завершения записи, извлеки карту и открой TEMP.CSV на компьютере.

```cpp
#include <SPI.h>
#include <SD.h>
#include <math.h>
float temperature(){
 int code=analogRead(A0);
 if(code<=0 || code>=1023) return NAN;
 float r=10000.0f*code/(1024.0f-code);
 return 1.0f/(1.0f/298.15f+log(r/10000.0f)/3950.0f)-273.15f;
}
unsigned long last=0;
void setup(){Serial.begin(9600);pinMode(10,OUTPUT);if(!SD.begin(10)){Serial.println("SD error");while(true){}}}
void loop(){
 unsigned long now=millis();if((unsigned long)(now-last)<1000)return;last=now;
 File file=SD.open("TEMP.CSV",FILE_WRITE);
 if(file){file.print(now);file.print(',');file.println(temperature(),2);file.close();}
 else Serial.println("Write error");
}
```

## Проверка

При интервале 1000 мс за минуту появляется примерно 60 строк; первый столбец — миллисекунды от старта, второй — температура. Небольшие отклонения периода связаны с записью и обработкой.

## Если не работает

- CS не совпадает с программой.
- Карта не поддерживается форматом библиотеки.
- Питание карты проседает при записи.
```callout
kind: mistake
text: >-
  SD-карта безопасно принимает 5 В напрямую на сигналы. Закрытие файла важно для сохранения
  буферизованных данных.
```
