## Цель

Соберём автономный регистратор температуры: Arduino измеряет NTC раз в 10 секунд и записывает строку «время, температура, код АЦП» в файл LOG.CSV на SD-карте по SPI. Потом откроем файл на компьютере и построим график. Проект соединяет SPI, датчики и работу с файловой системой.

## Что понадобится

- Arduino Uno или Nano.
- Модуль SD-карты (SPI, со стабилизатором 3,3 В и преобразователем уровней), SD- или microSD-карта 2–32 ГБ, отформатированная FAT16/FAT32.
- NTC 10 кОм и резистор 10 кОм.
- Компьютер с кардридером для чтения файла, Excel/LibreOffice или Python для графика.
- Осциллограф Rigol DHO804, лабораторный блок питания WANPTEK TPS3010 и резистор 1 Ом для опыта на стенде.

## Расчёт

- **Размер строки:** «12345,23.4,512» + перевод строки ≈ **15 байт**.
- **Объём за сутки:** при записи раз в 10 с: 8640 · 15 ≈ **130 КБ**; за год — 47 МБ.
- **Срок записи на карту 2 ГБ:** 2·10⁹ / 130 000 ≈ 15 000 суток — ёмкость практически неисчерпаема.
- **Время записи строки:** открытие и закрытие файла — десятки миллисекунд; для интервала 10 с незаметно.
- **Скорость SPI:** SD.begin по умолчанию 4 МГц (на Uno); запись строки в блок 512 байт ≈ 1–2 мс.
- **Потребление:** модуль SD с картой в записи до 100 мА, в простое 1–5 мА.

## Сборка по шагам

1. Отключи питание. Модуль SD: VCC → 5V, GND → GND, SCK → D13, MISO → D12, MOSI → D11, CS → D10.
2. NTC: 5 В → 10 кОм → A0 → NTC → GND.
3. Отформатируй карту в FAT32 и вставь её в модуль.
4. Загрузи скетч:

```cpp
#include <SPI.h>
#include <SD.h>

const int CS = 10;
const int NTC = A0;
const float R_FIX = 10000.0, B = 3950.0, T0 = 298.15, R0 = 10000.0;
unsigned long last = 0;

float readTemperature(int &raw) {
  raw = analogRead(NTC);
  float rn = R_FIX * raw / (1024.0 - raw);
  return 1.0 / (1.0 / T0 + log(rn / R0) / B) - 273.15;
}

void setup() {
  Serial.begin(9600);
  if (!SD.begin(CS)) {
    Serial.println("SD: ошибка инициализации");
    while (true) {}
  }
  File f = SD.open("LOG.CSV", FILE_WRITE);
  if (f) { f.println("time_s,temp_C,raw"); f.close(); }
  Serial.println("Запись начата");
}

void loop() {
  if (millis() - last >= 10000UL) {          // раз в 10 с
    last = millis();
    int raw;
    float t = readTemperature(raw);
    File f = SD.open("LOG.CSV", FILE_WRITE);
    if (f) {
      f.print(millis() / 1000); f.print(',');
      f.print(t, 1);            f.print(',');
      f.println(raw);
      f.close();                             // закрытие = данные на карте
    }
  }
}
```

5. Дай поработать 10–15 минут, нагрей и охлади NTC.
6. Отключи питание, достань карту, открой LOG.CSV на компьютере и построй график.

## Проверка

Ожидай: файл LOG.CSV содержит заголовок и по строке каждые 10 с; размер растёт на 15 байт каждые 10 с; на графике видно нагрев и остывание NTC. Если вынуть питание в момент записи, последние данные до закрытия могут быть потеряны — но файл остаётся читаемым.

## Если не работает

- **«SD: ошибка инициализации».** Проверь линии MOSI/MISO (не перепутаны), CS = D10, питание 5 В, формат FAT32 и целостность карты.
- **Файл пуст.** Файл не закрывался или питание отключили сразу после записи; всегда вызывай close().
- **Строки обрываются.** Слишком короткое питание: питание модуля нестабильно (ток записи до 100 мА); используй отдельный источник.
- **Данные «скачут».** Шум АЦП: усредняй 16 отсчётов.
- **Карту не видит компьютер.** Не извлекай карту при записи; проверь файловую систему.
