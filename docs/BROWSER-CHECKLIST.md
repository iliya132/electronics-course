# Проверка сайта в браузере

Проверять на отдельной тестовой базе: PORT=3003 и DB_PATH=data/review-qa.sqlite
(в PowerShell: $env:PORT='3003'; $env:DB_PATH='data/review-qa.sqlite'; npm start).
Основной прогресс не использовать для сценариев импорта и сброса.
Повторить при ширинах 360 / 768 / 1280 px в светлой и тёмной теме.

- [ ] Пройти урок: ответить на все вопросы, завершить; статус, заметка и прокрутка сохраняются после перезагрузки.
- [ ] Перейти с урока на главную: заголовок вкладки снова «Электроника».
- [ ] Заблокировать рисунок через Network request blocking: остальной урок доступен, вместо рисунка выноска.
- [ ] Открыть неизвестный маршрут: есть ссылка «К курсу».
- [ ] Навести, сфокусировать Tab и коснуться термина: определение видно и не выходит за экран.
- [ ] Ответить неверно в «Вспомним»: подсказка работает, исходный ответ урока не меняется.
- [ ] Завершить обязательные уроки темы: на последнем есть ссылка на экзамен.
- [ ] Провалить экзамен, пересдать и сдать: разбор появляется после сдачи, следующая попытка имеет новый набор.
- [ ] Закрыть незавершённый экзамен и начать снова: возобновляется та же попытка с ответами.
- [ ] Ввести abc в числовой вопрос: «Далее» оставляет на месте и показывает ошибку под вопросом.
- [ ] Вопрос multi сопровождается текстом «Можно выбрать несколько вариантов».
- [ ] После завершения урока новые карточки ждут сутки; ошибки в вопросах теста и на экзамене карточек не создают, в повторении только карточки уроков.
- [ ] Повторить карточку: после «Помню» / «Не помню» она исчезает из текущей очереди.
- [ ] Сменить тему и размер шрифта: настройка сохраняется, перезагрузка сразу применяет кэш темы.
- [ ] Экспортировать, сбросить тестовый прогресс и импортировать: ответы, заметки и настройки восстановлены.
- [ ] Импортировать файл с неизвестным block_id: понятная ошибка, текущие данные сохранены.
- [ ] Сбросить тестовый прогресс: без слова СБРОСИТЬ сброс не выполняется, с подтверждением очищается.
- [ ] Виджеты: u_max=6 ограничивает напряжение, соединение переключается флажком, сквозной ток H-моста красный.
- [ ] Графики buck / ohm-law / rc-charge: подпись Y не перекрывает верхнее деление.
- [ ] Итоги курса содержат пять ссылок на итоговые проекты.
- [ ] Калькулятор (значок в шапке или Alt+C): `4,7к || 10к` даёт 3197,278912, `R1 = 4к7` и затем `R1*2` даёт 9400; панель переживает переход между страницами и перезагрузку, Esc закрывает, на 360 px она прижата к низу.
- [ ] В Network нет запросов к внешним хостам, в Console нет ошибок JavaScript.

## Обход страниц

Открой сайт и установи ширину в DevTools. Скрипт открывает уроки и сохраняет факт их
посещения, поэтому запускай его на тестовой базе. Выполни в консоли браузера:

```js
const sleep = ms => new Promise(resolve => setTimeout(resolve, ms));
const course = await (await fetch('/api/course')).json();
const routes = ['#/', '#/review', '#/glossary', '#/search', '#/settings', '#/summary',
  ...course.topics.map(t => '#/topic/' + t.id),
  ...course.topics.flatMap(t => t.lessons.map(l => '#/lesson/' + l.id)),
  ...course.topics.filter(t => t.exam).map(t => '#/exam/' + t.exam.id), '#/exam/final'];
const bad = [];
for (const route of routes) {
  const ready = new Promise(resolve => {
    let timer;
    const finish = ok => {
      clearTimeout(timer);
      document.removeEventListener('route:ready', handler);
      resolve(ok);
    };
    const handler = () => finish(true);
    document.addEventListener('route:ready', handler);
    timer = setTimeout(() => finish(false), 4000);
  });
  if (location.hash === route) {
    const {navigate} = await import('/js/router.js');
    await navigate();
  } else location.hash = route;
  const ok = await ready;
  await sleep(50);
  if (!ok) bad.push(route + ': не загрузилась');
  if (document.documentElement.scrollWidth > innerWidth + 1) bad.push(route + ': горизонтальная прокрутка');
  if (/NaN|Infinity|undefined/.test(document.getElementById('main').innerText)) bad.push(route + ': неверное число');
}
console.log(bad.length ? bad : 'Все ' + routes.length + ' страниц в порядке');
```
