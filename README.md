# Электроника: от тока до ESP32

Локальный самоучитель на русском: **19 тем, 185 занятий** (140 уроков, 40 проектов, 5 разборов плат), 21 интерактивная модель, 99 терминов, опыты на лабораторном стенде в 157 занятиях, 366 иллюстраций в занятиях. В 17 тематических банках 865 вопросов; итоговый экзамен содержит 30 вопросов.

## Что внутри

- **Содержание:** 19 тем — от заряда и закона Ома через диоды, транзисторы, операционные усилители, цифровую логику, микроконтроллеры, Arduino и ESP32 до проектирования платы в KiCad и итоговых проектов. К каждому занятию указано время.
- **Формат занятий:** текст с проверками и предсказаниями, пошаговые разборы, интерактивные модели, рисунки, **опыты на стенде** (блок питания, мультиметр, осциллограф, генератор, LCR-тестер), карточки повторения (коробки Лейтнера), экзамен на каждую тему и итоговый экзамен.
- **Стенд вместо батареек:** все опыты рассчитаны на лабораторный блок питания WANPTEK TPS3010, мультиметр Rigol DM858E, осциллограф Rigol DHO804, генератор OWON DGE2070 и тестер FNIRSI LCR-P1. Первое занятие курса объясняет блок питания и мультиметр, а занятие «Осциллограф и генератор сигналов» в теме про цепи добавляет осциллограф и генератор. Подробности — в [docs/LAB-BENCH.md](docs/LAB-BENCH.md).
- **Стек:** Node.js, Express, SQLite (better-sqlite3), Markdown и YAML для материала, обычный браузерный JavaScript без сборщика. Без регистрации, CDN и телеметрии: сайт работает локально.

```text
content/   уроки (Markdown), экзамены и словарь (YAML) — источник правды
public/    интерфейс, модели-виджеты и SVG-рисунки
server/    API, оценивание, повторение, база данных
scripts/   валидация материала и генераторы рисунков
test/      автоматические тесты
docs/      заметки по проверке интерфейса и ревью
```

Решения, ограничения и правила оценки времени занятий — в [NOTES.md](NOTES.md), результаты приёмки — в [ACCEPTANCE.md](ACCEPTANCE.md), источники — в [SOURCES.md](SOURCES.md).

## Запуск

Нужен Node.js 20+; проект проверен на Node.js 24.19.0 в Windows.

```powershell
git clone https://github.com/iliya132/electronics-course.git
cd electronics-course
npm install
npm start
```

Открой **http://localhost:3000**. Первая установка скачивает зависимости из npm и бинарный модуль SQLite; после установки сайт работает без интернета. Иконки, шрифты, код и рисунки обслуживаются локально. Для воспроизводимой установки с готовым lock-файлом используй `npm ci`.

Если порт занят другим приложением:

```powershell
$env:PORT = '3001'
npm start
```

Для следующего запуска на стандартном порту: `Remove-Item Env:PORT`. Сервер слушает только `127.0.0.1`. Остановить его можно Ctrl+C. Если для выбранной версии Node нет готового better-sqlite3, установщик может потребовать инструменты сборки C++; на проверенной Windows/Node 24 использован готовый модуль.

## Как учиться

- На главной выбери «Продолжить». Уроки открываются по порядку: доступны пройденные и один новый, следующий откроется после «Завершить урок». Статус «В процессе» появляется после первого ответа, а не при открытии.
- Ответь на все проверки и предсказания, затем нажми «Завершить урок». Ошибка не запрещает завершение: она создаёт карточку повторения.
- Необязательные занятия отмечены отдельно и не блокируют экзамен темы. Обязательные проекты входят в допуск.
- В экзамене можно пропускать вопросы, возвращаться и продолжать незавершённую попытку из истории. Правильные ответы открываются после сдачи.
- Экзамены тем: 10 вопросов, порог 70%. После всех 17 сданных экзаменов доступен финал: 30 вопросов, по 1–2 из каждой темы.
- «Повторение» использует пять коробок Лейтнера. При верном ответе интервал увеличивается, при ошибке карточка возвращается в первую коробку.
- В уроках есть заметки с автосохранением, позиция чтения, пошаговые примеры, подсказки и ссылки на практику.
- Для расчётов есть калькулятор и блокнот: значок в шапке или Alt+C. Панель остаётся открытой при переходе между уроками, карточками и экзаменом, её можно перетащить за заголовок. Приставки пишутся после числа (`4,7к`, `100н`, `4к7`), параллельное соединение — `||`, переменные — `R1 = 4,7к`; нажатие на результат копирует число. Содержимое хранится в `localStorage` браузера и не входит в экспорт прогресса.
- В проектах с прошивкой можно скачать `.ino`. Библиотеки, подключения и модель платы описаны рядом со скетчем.

## Данные и резервные копии

Прогресс хранится в `data/app.sqlite`, материал — в `content/`. SQLite и тестовые данные не входят в Git. При переносе прогресса используй «Настройки → Экспорт JSON». Импорт **заменяет** текущий прогресс после отдельного нажатия кнопки; некорректный файл не должен частично стирать базу. Сброс требует ввода слова `СБРОСИТЬ`.

Не копируй только файл SQLite во время записи: рядом могут находиться WAL/SHM. Экспорт JSON работает при запущенном приложении. Для отдельного тестового экземпляра можно задать `DB_PATH=data/my-test.sqlite` и другой `PORT`.

## Команды проверки

```powershell
npm run validate
npm test
npm run figures
npm run dev
```

- `validate`: структура уроков, ссылки, предпосылки, ответы, изображения, виджеты, экзаменационные банки.
- `test`: оценивание, карточки, API, резервные копии, расчёты, прохождение всех занятий и экзаменов, повторное открытие SQLite, синтаксис браузерных модулей.
- `figures`: пересоздание SVG из исходных формул и схем.
- `dev`: перезапуск сервера при изменении `server/` и `content/`.

## Добавление урока вручную

1. Создай Markdown-файл в существующей папке `content/topics/NN-topic/`. Номер в имени задаёт порядок. Для новой темы добавь `topic.yml` и её папку в `content/course.yml`.
2. Возьми структуру `content/topics/01-basics/01-charge-current.md`: front matter с уникальным `id`, названием, иконкой Lucide, summary до 140 символов, уровнем, временем (`minutes`, считается по правилам из NOTES.md), предпосылками, целями, терминами и карточками.
3. Добавь 3–5 коротких разделов с проверками, минимум два рисунка, разобранный пример, самостоятельную числовую задачу, типичную ошибку, 3–5 заданий практики, повторение и итог.
4. Специальные fenced-блоки: `quiz`, `predict`, `figure`, `example`, `widget`, `callout`, `recall`, `checkpoint`, `bench`. Содержимое — YAML. Для обычного кода используется `cpp`/другой известный язык.
5. Числовой ответ хранится числом; единица указывается отдельно. Допуск задаётся в процентах. Множественный ответ — список индексов, начиная с нуля.
6. Если у занятия есть физический опыт, добавь блок `bench` («Опыт на стенде»): поля `title`, приборы (`psu`, `dmm`, `scope`, `awg`, `lcr` — настройки строкой), `warn` (по желанию), `steps` и `expect`. Для блока питания всегда указывай предел тока. В уроках блок ставят в раздел «## Опыт на стенде» перед «## Практика», в проектах — перед «## Проверка».
7. Создай генератор `scripts/figures/<id>.js` с экспортом `generate()`. Используй `scripts/lib/plot.js` и `schematic.js`, затем запусти `npm run figures`.
8. Добавь минимум три новых вопроса в `exam.yml` своей темы. Размер банка — не менее 2,5 размера попытки; распределение сложности примерно 40/40/20.
9. Запусти валидацию и тесты, проверь урок в обеих темах и на мобильной ширине.

Для `kind: project` используй структуру любого проекта; для `teardown` — разбор платы. Темы 18 и 19 не имеют собственного экзамена.

## Авторские исходники курса

Готовый сайт читает только `content/` и `public/`. Источник правды — Markdown и YAML в `content/topics/`; рисунки уроков строятся скриптами `scripts/figures/<id>.js` (библиотеки `scripts/lib/fig.js`, `scripts/lib/diag.js`):

```powershell
node scripts/figures.js <id-урока> ...
npm run validate
npm test
```

**Устарело:** прежний генератор `scripts/course/*` (шаблонные уроки) больше не используется. Не запускай `scripts/course/compiler.js`: он перезапишет переписанные вручную уроки шаблонным текстом. `scripts/read-curriculum.js` нужен только для первоначального разбора программы.
